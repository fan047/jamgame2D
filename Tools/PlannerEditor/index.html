Holedown 策划配置工具

离线使用 · 不需要 Unity · 不上传文件

当前编辑：内置默认示例，不是游戏当前文件。

修改现有配置，请先同时导入游戏 Config 文件夹中的 settings.json 和 level.json。导出只是下载，不会自动写回游戏目录。

1. 球参数与配置版本

版本只用英文字母、数字、点、下划线或连字符（1–32 字符）。默认球直径 0.24，大于标准块间隙 0.1；钻缝需要留出实际通道。

2. 棋盘与补行

01234567

点击空格定位新增块，点击已有块选中编辑。初始棋盘顶部为第 7 行、底部为第 0 行。此处只显示格子，不模拟球运动。

新增方块

只能在最后一条补行中放唯一目标。移动目标时，先取消旧目标或删除旧块，再设置新目标。允许编辑中暂时没有目标，但通过完整校验后才能导出。

3. 校验、导出与试玩

  1. 通过校验后，分别下载两份配置。
  2. 把下载文件替换到 游戏 exe 同目录的 Config 文件夹，确保名称完全为 settings.json 和 level.json（不是 settings (1).json）。
  3. 切回游戏点击 Reload + Restart，旧局会被丢弃，从新配置重新开始。
  4. 检查 HUD 的 S（球参数）/ L（关卡）版本是否与这里一致，再开始试玩。

两个文件都缺失时游戏使用内置配置；只缺一个或文件错误时会报错并禁止发射。浏览器校验不能代替游戏实射验证，尤其是通道宽度与高速碰撞。
