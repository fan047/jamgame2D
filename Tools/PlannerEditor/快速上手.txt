Holedown 成长版 P1 策划快速上手（不需要 Unity）

每次构建单独保存在 Builds/01、Builds/02……，本运行目录位于对应编号的 Windows 子目录。
新构建不覆盖旧包；升级时需手动将旧包的 Config 复制到新包，先备份，height=2 配置必须使用 P1 程序。

1. 运行 HoledownGrowth.exe 试玩。
2. 双击 PlannerEditor/index.html，用 Chrome 或 Edge 打开离线编辑器。
3. 在编辑器里同时导入本目录 Config/settings.json 和 Config/level.json。
   刚打开编辑器时显示的是内置示例，不会自动读取游戏当前文件。
4. 选择关卡、初始棋盘或补行。表格血量和球参数失焦/Enter 提交，Tab/Enter 连续改血。
   位置、形状、类型需点击应用。离开未应用属性时选择应用、丢弃或取消；错误数值可按 Esc 取消。
   勾选后可批量设值/加减；“只选普通块”不含奖励和目标。整批全成或全败，一次撤销，最多 50 步。
   目标必须唯一，而且位于最后一条补行。最终关无奖励，每个非最终关最多一个 +3/+5 奖励块。
   形状为 1×1、2×1、1×2；竖块仅限初始布局，从 row 向上占两行。工具展示可能入关球数，不代表一定拿满奖励。
   校验通过不等于通道可玩，仍需实射测试。
5. 修改球参数版本/关卡版本，分别下载 settings.json 与 level.json。
6. 把下载的两份文件替换到游戏 Config 文件夹，名字必须完全一致。
   浏览器下载不会自动更新 Config；注意不要留下 settings (1).json 这样的文件名。
7. 切回游戏点击 Reload + Restart，当前局会被丢弃，新局读取刚保存的配置。
8. 检查 HUD 的 Config: S:版本 / L:版本，再开始测试。只有配置改变时不需要重新构建游戏。

配置约定：settings schemaVersion 为 1，level 导出为 2；旧单关 v1 可导入并转换为单关 v2。
不要把成长版 v2 配置交给旧 MVP 程序。version 为 1–32 个英文字母、数字、点、下划线或连字符。
球数、血量使用正整数；数值必须为有限正值；半径小于 0.5、角度小于 90。
默认球直径 0.24，不能通过只有 0.1 宽的标准块缝，请留出真实可通行空间。
初始行号为 0–7，底部为 0；补行内 row 一律为 0、height 必须为 1；列号为 0–7。
竖块完整占两行，不可重叠或超出顶部；推进后顶端进入第 8 行即失败。
受击时只有图形轻微缩放，碰撞体和文字不缩放；剩余血量 ≤2/3 显示轻裂痕，≤1/3 显示重裂痕。
比例以初始最大血量计算，推进不重置裂痕；原来的三关数值布局保持不变。

可选竖块演示：先备份 Config/level.json，将 Config/Examples/level-vertical.json 复制为 Config/level.json，
点击 Reload + Restart；HUD 关卡版本应为 growth-p1-example，第 1 关 column=4、row=1 有 6 血竖块。
演示文件不能直接按原名导入工具，请先复制/重命名为 level.json，再与 settings.json 一起导入。
height=2 配置需要本 P1 程序；旧 P0 成长版程序会明确拒绝，不能只更新工具不更新游戏。
每轮结算先判断目标胜利，否则上移补行并判断越线失败。

成长规则：奖励块完全击毁后暂存，过关后才确认；本关球数不变，下一关才增加。
Next Stage 手动进下一关；最后一关显示 Run Complete。
Retry Stage 仅失败后可用，保留入关球数、丢弃本次暂存奖励。
Restart Run 从已载入快照的第一关重开，不读取修改后的文件。
只有 Reload + Restart 或重新启动程序才读取文件；重载会清空整轮成长。

错误处理：
- 两个 JSON 都不存在：使用内置默认配置，HUD 显示 Built-in。
- 只缺一个、JSON 损坏、字段拼错或关卡非法：显示 Config error，禁止发射，不悄悄回退。
- 数组下标从 0 开始；incomingRows[1].blocks[2] 指第 2 条补行的第 3 个方块。
- 修正文件后点击 Reload + Restart；错误面板上的重开按钮同样会重新读取。
- 修改文件不会影响正在飞行的一局，必须主动重载或重新启动。

请先备份原文件；编辑器关闭或刷新前确认已导出。“已请求导出”不是已保存到游戏，请核对下载。
settings 和 level 独立提示修改/导出状态。游戏不会把伤害和推进写回 JSON。
程序重建时保留输出目录已有 Config 文件，不覆盖策划调参；需要恢复示例可在编辑器里还原默认后重新导出。
不要修改 Data、MonoBleedingEdge、DLL；请把整个运行目录一起拷贝，不能只拷贝 exe。
