## 3. 导入、尺寸与颜色

### 3.1 导入默认值

- 新正式图使用 Sprite（2D and UI）、Single、中心 Pivot、Full Rect。
- 默认 PPU 为 256，开启适当透明处理、颜色图使用 sRGB，Bilinear、无 Mipmap；首次试装保留足够分辨率，背景 Max Size 至少覆盖 1920 高度。
- 导入设置由程序负责；像素风若由美术选定，应在 A 批试装时确认 Point 过滤，不等整套完成后才改。
- 保留现有 BoxCollider2D／CircleCollider2D，不从原画透明轮廓生成新的玩法碰撞形状。

PPU 表示多少像素对应一个世界单位，不能把画布像素当成格子尺寸。[Unity PPU 说明](https://docs.unity3d.com/6000.4/Documentation/ScriptReference/TextureImporter-spritePixelsPerUnit.html)

### 3.2 独立适配 Sprite

在单位缩放的容器下，以 Sprite.bounds.size 作为原生宽高：

```text
scale.x = desiredWidth / sprite.bounds.size.x
scale.y = desiredHeight / sprite.bounds.size.y
```

该 bounds 以世界单位表达原生尺寸；实际对象的 Transform 仍需单独处理。[Unity Sprite.bounds](https://docs.unity3d.com/6000.4/Documentation/ScriptReference/Sprite-bounds.html)

- 方块目标尺寸始终为 (Width-0.1, Height-0.1)；三种底图分别选择，不能把横图原生的 2 倍宽度再乘一次。
- 裂痕单独按同一目标矩形适配，不直接继承底图的归一化缩放；VisualRoot 只承载统一 0.94–1 的受击系数。
- 允许格间隙带来的小幅轴向适配，验收时检查圆角和纹理不过度变形；不把正方底图当作正式横／竖图拉伸。
- 球目标直径为 settings.ballRadius×2，与 PNG 的原始分辨率及 PPU 无关。
- 发射点保持 (4,9)，首轮替换原约 0.3 尺度的视觉，不改变 Origin 或回收线。
- 新图片若有大量透明留边先回美术检查，不通过偷偷增大 Collider 解决。

### 3.3 彩色图与真闪白

正式彩色模式以白色 Renderer 乘色为基准，身份用标记层和局部强调色表达。禁止继续把普通青、奖励紫、目标金整体乘到彩色底图或彩色碎片。

使用适配当前 URP 2D 的 Sprite Unlit 闪白材质，增加 _FlashAmount 参数：0 为原画，1 为白色，保留纹理 alpha。每个 Renderer 通过 MaterialPropertyBlock 设置自身参数；不能修改共享材质导致所有块一起闪。

Renderer.SetPropertyBlock 可设置单 Renderer 的材质参数覆盖。[Unity SetPropertyBlock](https://docs.unity3d.com/6000.4/Documentation/ScriptReference/Renderer.SetPropertyBlock.html)

沿用 0.06 秒闪白和现有缩放时序；结束、重绑、禁用、切关或重试时清零参数并恢复基准尺度。底图与裂痕一起受击，数字和身份标记不缩放。

未绑定新主题的旧测试夹具可保留占位显示，但必须新增正式彩色模式测试，不能只因旧白色 Square 仍能闪就判定通过。

## 4. 背景、身份与反馈

### 4.1 背景和主视觉

- 背景独立 Renderer 放在最底层，以均匀缩放覆盖实际相机视口：scale=max(viewWidth/spriteWidth, viewHeight/spriteHeight)。
- 横屏允许裁切背景纯装饰区；棋盘、Logo、按钮和 HUD 独立布局，不随背景裁切。
- 默认开始页复用游戏背景与独立 Logo，Logo 等比装入 UI 区域；文字按钮继续用程序 UI。
- 球、方块、危险线、数字始终可辨；不因背景替换移动相机、墙或危险线。

### 4.2 数字与身份

底图、裂痕、徽记与文字按顺序分层。Health 与 RewardValue 是程序数据；目标使用独立图标，不靠把星号烘焙进每张方块图。

保留旧占位回退时允许沿用旧字符标记；绑定新徽记后避免同一身份重复叠多个图标。完整样片检查普通、奖励与目标的区分，不只检查颜色。

### 4.3 击碎与特殊表现

- 普通碎片沿用约 5 片、0.3 秒；只有视觉效果，无碰撞。
- 奖励只响应已接受的奖励击碎结果，显示 +3／+5 和下一关生效提示，约 0.6 秒；附约 0.35 秒局部光效。
- 目标只响应已接受的目标击碎，附约 0.3 秒强调。不能直接调用通关、清球或提前进入下一关。
- 回调时先复制位置、身份和奖励值，再启动效果，不在后续协程中依赖已销毁 BlockView 取数据。
- AttemptReset 时清除碎片、飘字、光效和闪白残留；表现事件不能再次记录奖励。

首轮保留现有占位音。策划文件到达后另做可配置 AudioClip 接入，保留限频；只能释放程序自己创建的占位 Clip，不能销毁外部素材资产。音效缺失不阻塞本轮视觉验收。

## 5. 开始页与配置生命周期

GameFlowController 增加运行层展示状态 AppPhase：Loading、Title、Playing、Paused、ConfigError。它管理入口与暂停，不替代 Rules 中 GameSession 的关内状态机；Paused 保留原关内状态及全部球。

| 场景／命令 | 确定行为 |
|---|---|
| 首次启动 | 加载并校验配置快照；成功进入 Title，显示背景、Logo、Start；不发射 |
| StartGame() | 仅 Title 且配置就绪时有效；创建第 1 关尝试，进入 Playing |
| NextStage／RetryStage | 继续已加载快照，直接关内运行，不经过 Title |
| RestartRun | 清空成长并用现有快照直接开始第 1 关 |
| 游戏内 ReloadAndRestart | 读取新文件并直接开始第 1 关，不回开始页 |
| 开始前配置错误 | 显示已有错误与重载入口，Start 不可用；修正重载后回 Title |
| Esc／HUD Pause／活动关卡失焦 | 进入 Paused；返回焦点保持暂停，由新的 Continue 操作恢复 |
| 暂停层 Reload + Restart | 放弃原尝试、释放自有暂停状态，重读文件后直接第 1 关；错误可修正重载 |

StartGame 必须消耗完整按钮手势，双击只启动一次。GameFlow.TryFire 统一检查 AppPhase==Playing、焦点及输入许可，不能只靠遮罩覆盖 UI 来禁止发射。Continue、切关和重载同样等待旧手势释放与新的发射按下，具体仲裁按玩家输入方案执行。

### 重载实现选择

采用当前场景内重新加载配置：先 ClearAttempt，释放旧 LoadedConfiguration，读取新快照，创建 CampaignState，再按重载前是否已经开始决定进入 Title 或直接 BeginAttempt。

这是对当前 ReloadAndRestart 重载场景实现的明确替换，用于保证游戏内重载不重新弹开始页。Restart() 继续作为完整配置重载的兼容入口，不引入跨场景单例或一次性静态跳菜单标记。

读取失败则进入 ConfigError、保留错误位置和可操作的重载入口，禁止玩法输入，不混用上一份配置。保留“已经开始游戏”的重载意图，游戏内失败修复后仍直接开局；暂停层重载先释放自身持有的时间／音频暂停，成功或失败都不能残留 timeScale=0。重试／重开／重载仍创建新的 SessionId，拒绝旧球回调。

6. **分发**：新编号构建目录打包，确认正式资源和依赖均在包内；缺音效可以明确标记占位，不能伪称全套音效已接好。

## 7. 自测与交接

### 程序自测

- 同一测试图采用不同像素／PPU，球的直径和方块目标范围一致，Collider 不变。
- 三形状底图和共用裂痕正确居中；缩放、闪白、推进、重绑和重试后恢复正确。
- 彩色图与原 PNG 颜色一致；命中时确实变白、alpha 保留；其他块和共享材质不受影响。
- MaxHealth 阈值与完整占格原测试回归；补行竖块继续拒绝。
- 奖励／目标只播放一次对应反馈，表现不增加伤害或重复奖励；切关和重载清空残留。
- 首次启动不能发射，点击 Start 不发球，连点不创建两次尝试。
- HUD Pause 与 Esc 行为一致；失焦保留本轮，激活窗口的点击不执行 Continue 或 Reload，恢复点击不发球，具体按玩家输入验收清单执行。
- RestartRun、RetryStage、NextStage、ReloadAndRestart 分别验证快照和开始页行为；非法文件错误可恢复。
- 保留原真实物理、成长、重试和配置测试；调整确实依赖旧场景重载方式的测试，按行为验证，不能仅关闭开始门禁让旧断言通过。

### 实际画面与独立包

- 在 540×960 或 720×1280、1280×720 查看并保存截图；检查边缘、比例、文字、背景裁切、Logo 和按钮。
- 一张截图能迅速指出球、奖励、目标和危险区域；命中／击碎视频能区分普通、奖励与目标反馈。
- 完成第一关并进入后续灰盒关验证奖励生效；做失败重试、整趟重开和主动重载。
- 新编号 Windows 包从实际分发目录启动，确认主题、Shader、PNG 和 UI 引用不缺失。图可全局复用，后续关不增加专属美术任务。
- 最终记录素材版本、Theme 配置、配置版本、构建编号、Git commit hash、A／B 验收结果和仍使用占位的项目。
