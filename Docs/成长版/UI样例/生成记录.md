# 中文 UI 占位样例

日期：2026-11-04。用途：给团队与美术说明五类页面的排版、主次按钮层级及共用素材关系。

后续方向更新：用户决定让美术自由发挥，UI 流程暂不确定。本图与下方提示词保留为历史提案；其中的五页结构、9 项拆图、按钮布局及导航关系均未定稿，当前沟通依据见 [UI 美术开放简报](../UI美术制作清单.md)。

## 样例内容

从左到右为开始页、游戏 HUD、暂停页、关卡结算、配置错误。底部是 2 种面板、2 种按钮、3 个操作图标、2 个结算徽记，共 9 项共用素材的示意。

本图是占位排版参考。正式 UI 的方向、页面组织和素材范围由后续美术稿与团队讨论决定。未导入游戏 Assets，未修改 UI 场景、脚本、关卡或字体。

- “游戏标题”是文字占位，正式游戏名另行确定。
- 方块分布、目标位置、血量与球数用于排版示意，实际出现时机与奖励结算继续遵守现有玩法；不能按示意图直接改关卡规则。
- 字体外观是生成图中的示意。实际 UI 使用清单中的 Noto Sans SC 静态字体，中文由程序绘制。
- 暂停与结算弹层后的 HUD／按钮仅提供背景上下文，实际程序需按输入合同禁止穿透交互。
- 底部共用素材数量仅说明当时提案的复用思路，最终拆图与导出规格待方向稿确定后再讨论。该整张预览图作为历史参考保存。

## 生成提示词

以下为实际使用的两轮提示词，供追溯与调整。

### 首轮：五页布局

```text
Create a high-resolution landscape UI wireframe / layout reference sheet for a Chinese-language portrait 2D mine-themed ball-bouncing game. This is an intentionally simple PLACEHOLDER UI DESIGN EXAMPLE for artists, NOT finished game art and NOT a playable game screenshot. Use the supplied images as visual references: image 1 is the existing deep navy pixel-art mine background with blue stone frame and teal crystals; image 2 is the existing wordless stone-and-crystal title emblem. Preserve their visual identity and keep the large center quiet. Do not invent a game name or call it Holedown.

Layout: a single exceptionally clear landscape presentation sheet, approximately 3200x1500, with a neutral deep charcoal background, generous gutters and FIVE equally sized tall 9:16 screen mockups across the sheet. Each screen is fully visible, never cropped. Above the mockups, the Chinese heading must read exactly "中文 UI 占位样例". Smaller subtitle "布局参考 · 正式素材待美术制作". Above each screen, use its small Chinese screen label: "开始页", "游戏 HUD", "暂停页", "关卡结算", "配置错误". The artwork should show readable hierarchy and reusable components, not ornate finished illustration. Fonts should look like clean Noto Sans SC, with perfectly spelled, crisp Chinese text. Limit text to the exact short strings below. Use flat deep navy rectangular panels with a thin blue-grey pixel-edge border, simple gold primary buttons with dark text, and blue-grey secondary buttons with light text. No gradients, no excessive glow, no glass, no phone hardware frames, no English title, no watermarks.

Screen 1 开始页: the supplied mine background and small supplied wordless crystal emblem, a neutral text placeholder "游戏标题", a single large gold button "开始游戏", and a small hint "左键发射 · Space 召回". Keep emblem and title separate with generous spacing. No gameplay grid or debug HUD on this screen.

Screen 2 游戏 HUD: supplied mine background, top compact dark HUD with text "第 1/3 关" at left and a simple pause icon button at right. Next row "每轮 12 球" and "第 1 回合". Small subordinate line "下关奖励 +3". A small gold launch ring below the HUD. Below it a sparse downward dotted aiming line and only 7 grey-blue rectangular blocks concentrated in the lower half of the board, with short black health numbers such as 3, 4, 5, 8. One orange reward block with an up arrow and separate "+3" caption, one teal target block with a crystal pictogram. Keep the board and path unblocked. A bottom-centre blue-grey button with simple return-ball icon and the text "召回"; the small key hint "Space" may sit below. No reload button in the main gameplay area and no debug strings.

Screen 3 暂停页: the same mine background with game board visibly dimmed, overlaid by ONE reusable deep-blue stone-edged central window. Window heading "已暂停". Large gold button "继续游戏". Below it a blue-grey secondary button "重载配置并重开". Small subordinate note "读取文件，从第 1 关重开". Center all controls in the panel and give the two actions clear primary/secondary hierarchy.

Screen 4 关卡结算: same dimmed background, the same reusable window from screen 3. A simple gold faceted success medal, heading "本关通关", small lines "已获得奖励 +3" and "下一关每轮 15 球". Gold button "下一关". Secondary blue-grey button "从第一关重开". Use the exact same panel and button shapes as other screens.

Screen 5 配置错误: same mine background and reusable window. Heading "配置加载失败". A short body line "请检查关卡文件" then exact filename "level.json". A gold button "重新加载". No game-over skull, no victory badge. Body copy must fit naturally with comfortable padding.

Along the bottom edge of the whole sheet, outside the screens, show a discreet component legend using small simple swatches and text: "共用：2 种面板 · 2 种按钮 · 3 个图标 · 2 个徽记". It should reinforce that this is a shared-component UI layout sample. Ensure consistent dimensions, whitespace, Chinese text accuracy, no overlapping labels, all text readable at full image resolution.
```
