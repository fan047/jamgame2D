# 策划工具工作台重设计 · 交付 11

## 本次结果

根据本机 `C:/Users/29742/.agents/skills/frontend-design/SKILL.md` 的设计流程，重新整理离线策划工具的信息层级与响应式布局。本次未安装外部 Skill、框架、字体或网络依赖。

原问题是：七列数值表被放在双栏页面的右侧属性区，数值输入占据固定宽度后，坐标、形状、类型和长表头被挤到逐字换行，右侧字段只能在窄容器里滚动。不是 JSON 或关卡数据损坏。

## 新布局

```text
工具标题                         关卡编辑 / 数值表 / 球参数 / 校验与导出
配置来源、导入及还原
撤销、重做
关卡选择、跳到布局、关卡管理
整关预览                         方块属性
                                 应用、取消、删除
当前布局数值表（独占整行）
勾选与批量修改、预览
七列表格
全局球参数与版本
校验、下载两份 JSON、试玩步骤
```

- 宽屏左右分区，900px 及以下把属性放在预览下方，不把两列硬挤在一起。
- 数值表独占工作台整行；短表头与操作说明分开，坐标／形状／类型不换行。表格最小宽度 780px，窄屏仅在表格内部横向滚动，输入框保留至少 120px 宽度。
- 球参数移到工作区下方，通过导航直达；全局设置不再挡住日常关卡编辑。
- 球数边界、发射分析与放置规则按需展开。错误校验、未应用属性确认、独立导出状态仍保留。
- 矿洞岩蓝 `#101b28`、面板蓝 `#192b3c` 与晶石青 `#73d8e3` 构成工作区；奖励紫 `#c6a0ed`、目标金 `#efc16c` 只用于表达块类型与重要状态。中文无衬线界面字，表格数字等宽对齐，文字与控件左对齐。
- 保留离线 `file://` 使用，不依赖服务、CDN 或安装 Node。键盘焦点可见，可跳过页头直接编辑，可用键盘滚动数值表。

没有修改 JSON 格式、规则校验、关卡内容、奖励算法、草稿保护、历史记录或导出语义；主要改动为 `index.html` 与 `styles.css`，以及快速上手和浏览器测试。

## 交付与使用

- 完整包：`Builds/11/Holedown-Planner-Workbench-11-Windows.zip`。
- 直接打开新版工具：`Builds/11/Windows/PlannerEditor/index.html`。
- 工程源码入口：`Tools/PlannerEditor/index.html`。
- 游戏：`Builds/11/Windows/HoledownGrowth.exe`；指定关测试：同目录 `策划测试.cmd`。

**11 是前端更新交付，不是重新编译 Unity Player。** 游戏程序与资源沿用已验证的[构建 10](全中文界面交付说明.md)，运行包保持中文；正式配置仍是确认的三关，补行 4、4、7。未重跑 Unity EditMode／PlayMode，也未为这次网页修改重启异常退出的 Editor。旧包 01–10 均未覆盖。

已有构建 10 的用户只需用新包的整个 `PlannerEditor` 文件夹替换对应旧文件夹，游戏 `Config` 不必改。也可直接用新包完整解压目录。请先保存或导出旧网页中未导出的修改，再关闭旧页面并打开新版；仍需主动导入自己的两份 JSON，网页不会自动读游戏文件。

验收建议：使用实际桌面窗口大小打开新工具，导入自己的配置；选中方块修改血量，检查整关预览、独立数值表、横向滚动、批量预览和导出，再到游戏内实射验证。
