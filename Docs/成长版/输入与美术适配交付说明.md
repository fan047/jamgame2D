## 已实现

### 输入与流程

- 命名动作 Map：HoledownAim、HoledownVolley、HoledownSystem；UI 模块显式绑定同一项目动作资产，UI Cancel 解绑，避免 Esc 双重消费。
- AimInput 保留原有坐标、角度、UI Raycast 和首次 CircleCast，发射输入由 PlayerInputController 适配。
- 左键按下发射一轮，按住不跨轮自动发射；Space 在 Volley 阶段复用召回；Esc／HUD Pause 只进入暂停。
- 统一流程意图、上下文代次、切换帧及独立释放门禁；UI 操作优先于发射，同帧暂停优先，旧代次请求失效。
- 首次加载配置后进入最简开始页，Start 才进入第 1 关。下一关、重试、Restart Run 直接关内运行。
- 暂停保留原 Session、球、连发等待及超时计时；Continue 恢复原 timeScale，包含 20 倍速；暂停音源保留播放位置。
- 活动关卡失焦自动暂停；返回焦点仍保持暂停。首次激活点击不执行 Continue，新的点击才恢复；Space 持有不阻塞独立的鼠标输入。
- 当前场景内 Reload + Restart 清理旧尝试、释放暂停状态、重读配置并从第 1 关开始；启动前配置错误修复后回 Title，游戏内修复后直接开局。

### 主题与表现

- VisualTheme 集中引用素材；SpriteSizing 按实际 Sprite.bounds 独立适配，不改变碰撞体。
- Block 的 VisualRoot 统一接受受击缩放；底图和裂痕为同级、分别适配，血量和身份标记不缩放。
- 新 SpriteFlash Shader 按当前工程 URP 2D Sprite 实现接入，保留 alpha，以 MaterialPropertyBlock 单独设置闪白，不修改共享材质。
- 正式彩色模式可保留原画颜色；球适配配置直径，三形状底图、裂痕、徽记和 Logo 均有绑定入口。
- SceneVisuals 支持背景等比覆盖与相机尺寸变化、发射点替换、开始页 Logo 等比显示。
- 奖励／目标击碎补局部短反馈；奖励飘字显示下一关生效，不额外记录奖励或提前触发胜利；切关／重载清除效果。

## 当前占位与正式接入要求

当前 Theme 保持 `originalColors=false`，球、方块和裂痕使用原有占位图。横／竖槽目前复用 Square，仅用于程序验证，不是正式长宽形状原画。

正式背景、发射点、Logo、奖励／目标徽记、三形状正式底图、正式裂痕仍待交付；碎片和短光效使用程序占位，音效仍为合成占位音。不得因有绑定入口就宣称这些素材已接好。

接入顺序仍按原方案：

1. A 批球、单格方块、背景先试装与验收。
2. 导入明确设置 Sprite、Single、FullRect、中心 Pivot，检查完整 Sprite.rect；确认 PPU／过滤和透明度。
3. 在 Theme 绑定正式图，开启 `originalColors` 后验证原色、真闪白、尺寸和碰撞不变。
4. A 通过后再接 B 批三形状、裂痕、徽记、发射点和 Logo，完成完整样片的主观视觉验收。

方案依据保留在 `VISUAL_DESIGN.md`、`Docs/成长版/美术接入技术方案.md`、`Docs/成长版/玩家输入方案.md`，本说明只记录本次实现与验证，不重写原需求。
