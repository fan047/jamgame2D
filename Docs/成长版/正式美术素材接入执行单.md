- HUD、开始／暂停／结果界面按舞台在屏幕上的区域检查与布局，避免菜单全屏宽而棋盘只在中央窄条。复用现有 UI 适配，只增加共享的舞台矩形／锚点数据，不写死某一种分辨率像素坐标。
- 当前相机在 LateUpdate 更新、指针在 Update 采样；启动／改尺寸当帧先同步相机投影和舞台矩形，或屏蔽该帧玩法输入，防止使用上一帧投影。仅改相机缩放而不处理更新顺序不能通过缩放窗口验收。
- 场景当前是固定 940×1240 的 WorldSpace Canvas，相机加高不会自动重排 UI；使用实际 Canvas／相机转换核对布局，不按 Screen Space Canvas 的假设修改。

## 6. 交付验收与证据

### 素材检查

- 除背景外，PNG 存在真实透明像素及有效可见主体；透明角、金环孔洞均正确。用两种不同底色查看，排除烘焙棋盘格、暗色方底、灰边和 JPEG 杂边。
- 底图没有 6、10、血量、箭头或水晶；身份徽记与数值分别由对应层显示。清除数字后的区域无明显色块补丁。
- 三形描边／光照一致，角色全套不因拉伸改变材质；实际屏幕尺寸下能识别金球、箭头和水晶。

- 正式 Theme 所有本执行单必需素材已绑定；来源清单与最终目录一致，保留 Unity .meta 和稳定引用。不存在仅在下载目录或工具输出目录可用的依赖。
