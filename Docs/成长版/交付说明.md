# 成长版 P0 交付说明

## 使用入口

- Windows 程序：`Builds/Windows-Growth/HoledownGrowth.exe`。
- 离线策划工具：`Builds/Windows-Growth/PlannerEditor/index.html`，Chrome / Edge 双击打开，不需要 Unity、服务器或网络。
- 运行目录内有 `策划快速上手.txt`。分发时拷贝整个目录或解压 `Builds/HoledownGrowth-Windows.zip`，不能只拷贝 exe。
- 源码工具：`Tools/PlannerEditor/index.html`；当前三关种子：`Config/level.json`。默认球参数版本 `demo-1`，关卡版本 `growth-1`。
- 旧的 `Builds/Windows` 和 `Builds/HoledownMVP-Windows.zip` 保留，不被成长版构建覆盖。旧 MVP 程序不能读取新 level v2。

## 已实现的范围

### 游戏

三关推进，奖励块为紫色 +3 / +5，目标块为金色。奖励完全击毁才暂存，本关每轮球数固定，通关后只影响下一关。

- `Next Stage`：非最终关通关后手动进入下一关。
- `Retry Stage`：仅失败后重试本关，保留入关球数，清除本次尝试的暂存奖励。
- `Restart Run`：清空成长，用已载入的完整配置快照从第 1 关重来，不读磁盘。
- `Reload + Restart`：停止当前尝试，重新读两份 JSON，清空成长并从第 1 关重来。
- 最终关通关显示 `Run Complete`，没有下一关按钮。
- HUD 显示关卡序号、当前关球数、回合、活动/待发球、补行、待结算奖励和配置版本。

重试、切关和重开会清理旧球、碰撞体和表现协程，创建新 Session 和独立棋盘。配置和成长不会写回原始 JSON。

### 策划工具

1. 同时导入当前游戏 `Config/settings.json`、`Config/level.json`。刚打开时只是内置示例，不会自动读取游戏文件。
2. 选择关卡与布局，在数值表连续编辑血量。球参数和已有块血量失焦 / Enter 提交；Tab / Enter 可以连续改血。
3. 无效输入保留为草稿，不污染有效模型；阻止切换和导出。按 Esc 或“取消未提交数值”恢复。
4. 位置、宽度、类型显式应用。离开尚未应用的属性时，选择应用、丢弃或取消，避免静默丢失。
5. 勾选后批量设值或加减。“只选普通块”排除奖励与目标。确认摘要列出各类数量，整批合法才生效，失败不部分修改。
6. 最多 50 步撤销 / 重做，包含结构和编辑上下文；撤销后新修改清空重做。输入框内保留原生文本快捷键。
7. 显示结构化错误并定位关卡 / 布局 / 块 / 字段，统计块数与总血量，展示可达入关球数的离散集合。
8. 两文件独立显示“未修改 / 有未导出修改 / 已请求导出，请核对下载”。可生成时间戳版本。
9. 导出下载后，手动替换游戏 Config 同名文件，检查没有浏览器添加的 `(1)`，再点击游戏 `Reload + Restart`，核对 HUD 版本。

支持旧 level v1 导入为一关，导出统一为 v2；settings 仍为 v1。严格拒绝重复 JSON 键、未知/缺失字段、非法奖励、溢出、重叠和目标错误。每个非最终关最多一个奖励块，最终关无奖励。

可复现的瞄准角（相对正下方，正数向右）：

- 第 1 关拿奖励：每轮 -4.4°；不拿：前四轮 +10°，第五轮 0°。
- 第 2 关不拿且入关 12 球：前四轮 0°，第五轮 -4.4°；入关 15 球：前四轮 -4.4°，第五轮 0°。

## 交付边界与剩余事项

- P0 只支持高度 1；P1 的竖块、受击缩放、裂痕尚未实现。工具和运行时都拒绝 height != 1。
- 不包含存档、关卡增删排序工作流、自动写回 Config 或在线编辑服务。
- Editor 默认读取项目根目录的 `Config`，与 Player 读取 exe 同目录 `Config` 的规则一致。两个 JSON 都缺失才回退内置单关，HUD 标为 Built-in；只缺一个或非法则停止发射并报错。
- 构建保留输出目录已有 Config，避免覆盖策划修改；需要恢复种子请在工具还原示例后重新导出，不要误认为重建会重置参数。
- 本机首次独立包日志出现 D3D12 PSO 缓存写入失败提示；窗口正常运行与退出，未因此修改全局缓存路径或项目图形设置。换机器仍需验证显卡与驱动环境。
- 主观手感、内容美术、更多机型与分辨率仍需人工体验；横竖屏基本布局已检查，不声称覆盖所有平台。
