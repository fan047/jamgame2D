# UI 美术开放简报（流程待定）

日期：2026-11-04。当前方向：美术自由探索，界面流程待定，程序继续使用现有占位。文件保留原路径，便于团队沿用已有链接。

## 1. 可直接转给美术的说明

我们在做一款矿洞主题的弹球打块游戏，现有矿洞、岩石、水晶、小球素材可作为背景参考。希望你们自由发挥，探索一套与游戏协调、信息清楚、有自己特点的 UI。

这轮先看你们的整体视觉和交互想法。页面数量、页面组合、按钮位置、入口顺序、跳转方式和最终素材数量都待定。已有程序界面和样例图是了解游戏的材料，方向稿可以提出不同的组织方式。

可以提交一张整体方向稿，也可以提交若干界面草图、局部组件或交互草图；形式与数量由美术选择。方向确定后，团队再整理正式界面流程、文案、素材拆分和接入规格。

## 2. 供设计理解的功能与信息

以下是游戏当前具备的能力和可能用到的信息，作为设计素材池。如何组合、哪些信息常驻、哪些按需出现，留给方向稿表达。

- 游玩信息：当前关卡、每轮球数、轮次、奖励收益及其生效时机。
- 操作能力：进入游玩、暂停与继续、召回球、关卡结束后的继续／重试／重开。
- 状态表达：游玩中、暂停、通关、整趟结束和失败。
- 技术反馈：配置加载错误、重载文件等已有程序占位；是否纳入正式 UI 视觉体系后续再讨论。

当前已有开始页、HUD、暂停与结果面板，属于实现现状。它们提供上述能力，不代表最终必须采用相同的页面划分或按钮流程。功能语义与奖励规则可参考 [构建 05 交付说明](正式美术样片交付说明.md)。

## 3. 美术可自由探索的内容

- 整体视觉语言：面板造型、材质、配色、装饰、图标和字体气质。
- 信息层级：玩家第一眼看到什么，球数、奖励与操作如何清楚表达。
- 界面组织：独立页面、浮层、场景内 UI 或其他合适方式；入口和页面间关系可以一并提出。
- 交互表现：操作反馈、状态变化、过渡和动效想法；可用草图或简单说明表达。

现有游戏以竖版场地为主，也会在横屏窗口运行，画面参考见下方链接。方向稿可考虑如何使用这些空间，具体布局和适配待定。

## 4. 保留的可读性与接入条件

- 球路、方块数字、目标和奖励应容易辨认，UI 与装饰为主要游玩区域留出阅读空间。
- 界面使用中文，数字和按钮文字清楚；关卡、球数、血量、奖励等动态数值由程序显示，图稿中可用示例文字说明排版。
- 当前游戏规则与数值继续作为功能基础；新的界面或交互想法待团队看稿后确认实现方式。
- 正式素材的文件数量、像素尺寸、九宫格、状态图、导出格式与交付批次，均在方向确定后再细化。

用户已提供字体目录 D:/Downloads/unity/Font。可选 Noto Sans SC 的 Regular／Medium／SemiBold 静态 TTF，路径为 static/NotoSansSC-对应字重.ttf；中文样本文案、常用标点和数字覆盖已只读核对。字体选择与排版可以继续探索，程序负责最终字体／TMP 接入及保留对应字体说明。
