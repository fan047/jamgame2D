## 1. 总览如何呈现

选中任意关后，同一张纵向总览从上到下展示初始棋盘和全部补行。初始棋盘为 8×8，上边是 `row 7`，下边是 `row 0`。后续每条补行单列一组，保持八列与初始棋盘对齐，按 `incomingRows` 顺序标为「补行 1」「补行 2」等。空补行也保留一组，最后一条补行有明确标记。

```text
选关  ·  导入 / 导出  ·  跳到初始棋盘 / 补行 N

整关总览（八列对齐）         选中块属性与当前布局数值表
初始棋盘（8 行）             当前位置：第 3 关 · 补行 2
补行 1（1 行）               血量 / 形状 / 奖励
补行 2（1 行）               选中块的编辑与批量操作
…
```

长关卡通过垂直滚动浏览。原布局下拉改为跳转定位，选择补行后卷到对应组，整关仍可继续滚动。方块显示血量和奖励数值，目标使用已有目标标记。初始竖块占两行，横块占两列。长数值可在选中块属性或数值表中读取完整值。

每个补行组的位置表达补入顺序。游戏在第 N 次推进时读取 `incomingRows[N - 1]` 并生成在 `row = 0`。总览按配置排列，游戏结算使用现有推进规则。 [棋盘推进](../../Assets/Holedown/Scripts/Rules/BoardState.cs)

## 2. 总览里怎么编辑

- 点击任意方块，选中状态和属性面板切到该方块所在布局，布局跳转下拉同步。属性标题显示当前关和组名，数值表显示该组的块。点击空格沿用新增块入口，坐标取该组的局部坐标。
- 血量的失焦或 Enter 提交以及属性的「应用」继续沿用当前交互。数值提交刷新该块的显示，保留视口、选中状态和输入焦点。放置预览显示在选中布局组内。切换组、跳转、导出等动作沿用草稿校验和应用／丢弃／取消对话框。
- 批量改值默认限定当前布局组，旁边显示作用范围。切换组时按现有逻辑清理旧组选中项，确保数组索引对应当前组。添加或删除补行、撤销／重做后同步组列表、跳转项和编辑位置。
- 错误定位先选对应关及布局组，再滚到该组并定位字段。普通改值保持滚动位置。通过跳转下拉、错误定位或新增补行明确导航时，才滚向目的组。

批量作用范围与空格交互是按现有行为选定的实现默认值。界面窄时可以把属性区移到总览下方，保留整关浏览、跳转和编辑入口。

## 3. 接手实现

当前 07 随包工具与源码的关键前端文件一致。布局下拉选初始棋盘或一条补行，渲染取 `state.blocks` 并选择 8 或 1 行。整关总览改造可以在现有离线工具内完成。 [布局渲染](../../Tools/PlannerEditor/editor.js) [随包工具](../../Builds/07/Windows/PlannerEditor/index.html)

- 在 `editor.js` 从 `state.stage` 读取初始棋盘和全部补行，复用一组棋盘渲染逻辑，以布局索引、块数据与组内行数作为输入。组标题、方块位置和点击目标来自同一份数据。渲染直接读取模型，编辑使用当前选中的布局状态。
- 保留 `#layout`、`guard`、`navigate`、`fillProperty`、`renderTable` 和 `locate` 对应的职责。总览点击先走草稿保护，再切换布局与选中块，统一更新编辑上下文。错误定位与跳转共用滚动到组的入口。 [编辑器逻辑](../../Tools/PlannerEditor/editor.js) [状态与历史](../../Tools/PlannerEditor/editor-state.js)
- 在 `index.html` 和 `styles.css` 组织总览滚动区、组标题及属性区，复用八列网格和目标／奖励／选中样式。让滚动区在数值提交时保持稳定。配置仍通过现有模型、校验和导出路径保存。 [页面结构](../../Tools/PlannerEditor/index.html) [样式](../../Tools/PlannerEditor/styles.css)
- 构建时确认离线 HTML、JS 和 CSS 都复制到新编号包，并从实际分发目录的 `PlannerEditor/index.html` 打开验收。更新随包策划说明，标注「整关总览」和「跳到补行」的用法。 [Windows 打包入口](../../Assets/Holedown/Scripts/Editor/WindowsBuild.cs) [策划说明](../../Tools/PlannerEditor/快速上手.txt)

## 4. 自测与交付

| 独立改动 | 自测通过条件 |
|---|---|
| 整关总览与跳转 | 用当前工程第 3 关检查 8 行初始棋盘与 7 条补行同时在总览中。顺序、八列对齐、竖块跨行、目标与奖励标记正确。跳到最后补行后能滚回初始棋盘 |
| 总览点选与编辑 | 从初始棋盘直接点到最后补行并修改其目标块血量，再切回初始布局。导出前后对比确认只改指定块。检查跨组草稿应用／丢弃／取消、放置预览、错项定位、普通改值后滚动位置和键盘编辑 |
| 结构与回归 | 新增、删除补行以及撤销／重做后总览和跳转项同步。切换关卡和组后批量作用范围正确。验证从总览导出的 JSON 可由现有模型与游戏读取，补行的 `row` 仍为 0 |
| 新编号包 | 实际从随包工具导入已确认的策划配置，完成浏览、跨组编辑、导出及游戏加载。在浏览器中验收窄窗口与长关卡，记录构建号、配置版本、实际关卡和补行数 |
