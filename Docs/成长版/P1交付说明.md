## P1 已实现

### 1. 竖向双格

- 支持 `1×1`、`2×1`、`1×2`，不支持 `2×2` 或更大形状。
- `1×2` 仅允许初始棋盘，row 表示最下面的占用行；竖块向上延伸两行。
- 完整矩形占格检查，包括与相邻行的横块重叠；不能超出顶部。
- 推进仍每轮上移一格，按 `Row + Height - 1 >= 8` 判断顶端越线失败，不再只检查锚点。
- 实际中心为 `(Column + Width/2, Row + Height/2)`，Collider 尺寸为 `(Width - 0.1, Height - 0.1)`；瞄准预览使用该 Collider。
- 补行始终 row=0、height=1，避免跨批次重叠。

### 2. 血量裂痕

- 每个 BlockState 保存不可变 `MaxHealth`，创建时等于配置血量。受伤、推进、视图重新 Bind 不重置；重试创建新棋盘并恢复初始状态。
- `Health / MaxHealth > 2/3`：完整；`(1/3, 2/3]`：轻裂痕；`(0, 1/3]`：重裂痕；归零按原击碎流程移除。
- 阈值使用整数比较，避免边界浮点误差和 Int32 乘法溢出。
- 裂痕独立叠图，位于底图之上、文字之下，避开数字中心。横块和竖块都能显示。
- 占位素材：`Assets/Holedown/Art/CracksLight.png`、`Assets/Holedown/Art/CracksHeavy.png`，由 `Assets/Holedown/Prefabs/Block.prefab` 的 BlockView 引用。美术可替换对应 Sprite，不必改伤害规则。

### 3. 受击缩放

- 0.04 秒缩至基础尺寸的 0.94，0.08 秒恢复。
- 每次命中重新从基础尺寸计时，不累积缩小；同一块最多一个受击协程。
- 只缩放 Visual 子节点及其裂痕层，Collider、根节点、数字和目标/奖励标记不缩放。
- 保留闪白、碎片、限频音效；重复闪白不再由多条旧协程互相抢颜色。
- 重新 Bind、移除或禁用块时终止表现并恢复基础尺寸。

### 4. 离线工具联动

- 属性面板用三种明确形状选择代替单独宽度；补行禁用竖块选项。
- 棋盘正确跨两行显示，表格显示完整形状。
- 未应用位置/形状有虚线预览，重叠时标红，顶部越界给出原因。仍需点击应用，离开时保留应用/丢弃/取消保护。
- C# / JS 对竖块、上半格重叠、2×2、顶部越界和补行限制保持一致。
- 竖块支持修改血量、批量、撤销重做、导入和 v2 导出，旧 v1 单关仍可导入并补 height=1。

## 如何立即体验竖块

原有默认三关及其难度种子未改，直接 Play 能看到受伤裂痕和缩放，但默认布局没有竖块。

### Unity Editor

1. 备份项目 `Config/level.json`。
2. 将 `Config/Examples/level-vertical.json` 复制为 `Config/level.json`。
3. 进入 Play Mode，或点击 `Reload + Restart`。
4. HUD 应显示 `Stage 1/3`、`L:growth-p1-example`；第 1 关 column=4、row=1 是 6 血竖块。
5. 体验完恢复备份，再主动重载。

### 独立包与策划工具

在 `Builds/01/Windows/Config` 下进行同样操作，使用其 `Examples/level-vertical.json`。想在工具继续修改，先将演示文件复制/重命名为 level.json，再与 settings.json 一起导入。

也可以不换示例，直接在工具的初始棋盘选择空位、形状 `1×2`，设置行列与血量，应用、导出后替换游戏 Config。工具不模拟球路，空间合法不保证关卡可通关。

配置 schema 不变：settings v1、level v2。**含 height=2 的配置必须搭配本 P1 程序**，旧 P0 程序会拒绝；不要仅更新工具而继续使用旧 exe。演示配置用于功能体验，不宣称已完成整关难度平衡。
