## 工具变化

### 整关总览

- 选中关卡后，同一纵向滚动区包含初始 8×8 棋盘与全部补行，八列对齐。
- 初始棋盘上方 row 7、下方 row 0；每条补行独立显示一行，局部 row 均为 0。
- 补行按配置顺序编号，空补行保留，最后一条明确标记。分组表示补入顺序，不模拟同时存在的游戏棋盘。
- 原布局下拉改为“跳到布局”：滚到指定组，不隐藏其他组。总览仍可随时滚回初始棋盘。
- 目标、奖励、竖块跨两行、横块跨两列及当前选中标记保留。长数值可通过属性、数值表或悬浮提示查看完整值。

### 点击与编辑

- 点击任意组内的方块，当前位置、属性标题、布局下拉和数值表同步到该组；空格新增使用该组局部坐标。
- 未应用放置预览只在当前组内显示。属性区与当前布局数值表位于总览右侧，窄窗口时位于下方。
- 血量失焦／Enter 提交保留滚动、选择及输入焦点。数值刷新复用已有总览按钮，避免失焦提交时移除按下的按钮、吞掉后续跨组点击。
- 位置／形状／类型等属性草稿仍需应用。跨组、跳转、导出前沿用应用／丢弃／取消保护；非法数值阻止导航，可用 Esc 取消。
- 批量操作只作用于明确标出的当前组；跨组及跨关清空旧勾选，不会把旧数组索引应用到新组。
- 新增／删除补行、撤销／重做同步总览、跳转项、当前位置与最后一条标记。错误定位选择相应关和组，再滚到该组及字段。
- 普通改值不自动导航；明确跳转、错误定位、新增补行、选关及导入／还原才导航到目的布局。
- 窄屏数值字段与控件不撑开页面；数值表可独立横向滚动。消息不再悬浮遮住总览末行。
