# 首批音效素材来源

八条交付文件在 `Assets/Holedown/Audio`，均为 48 kHz、16-bit、单声道 WAV。Unity 场景 `SampleScene` 的 `Feedback` 对象绑定了这八条音效，可在 Inspector 替换对应素材。

2026-11-09：`block_hit.wav` 与 `block_break.wav` 已按候选包 `Docs/中期版/音效试听包/矿石轻乐音候选/试听` 原位替换（同名同格式，GUID 与场景引用不变）。替换前文件与哈希备份在 `Library/Locus/tmp/audio-swap/before/`；其余六条未改动。
