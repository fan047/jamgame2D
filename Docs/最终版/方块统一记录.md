# 三组方块统一记录

日期：2026-11-10。范围：让青晶（1–3 关）、紫晶（4–6 关）、玫红金晶（7–9 关）三组方块共用同一套像素颗粒、外缘台阶与矿石明暗切面，只保留各组基色。裂痕、身份徽记、占格与碰撞边界不动。

## 原型与做法

- 原型取第 4–6 组：它的方／横／竖三形已经有统一的台阶轮廓、左上高光斜面与右下暗部，且三种角色（普通／奖励／目标）同源。
- 用 `Tools/UnifyBlockArt.py` 重生成 1–3 组与 7–9 组共 18 张：结构（剪影、台阶、颗粒、阴影位置）整体取自 4–6 组模板，颜色按**亮度分位映射**换成目标组自己的色阶——把目标组原图按亮度分 64 档统计出「亮度→颜色」表，再按模板每个像素的亮度查表取色。这样既换掉了旧画法的柔和斜面，又保住了各组原有的色相与明暗层次。
- 4–6 组自身不改，作为模板与基准。
