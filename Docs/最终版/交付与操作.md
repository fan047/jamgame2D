## 策划改关与实测

1. 备份当前配置。在工作台同时导入正在测试的 `settings.json` 与 `level.json`。刚打开工作台时展示内置示例，导入后才是自己的配置。
2. 在整关总览编辑初始棋盘和所有补行。可新增、复制、重排关卡，通过数值表连续改血量或批量调整选中项。放置、形状与类型改动按面板提示应用。空补行有独立位置，校验报错可定位到关卡和布局组。
3. 校验后分别导出两份 JSON，覆盖当前 exe 同级 `Config` 下的同名文件。注意浏览器下载可能附加 `(1)`。Unity Editor 使用工程根目录 `Config`。工作台导出不会自动写入游戏目录。
4. 打开策划测试，选关后可选基础球数、满前关奖励或手填正整数。修改文件后暂停并点「重载当前关」，核对 HUD 的配置版本和生效球数，再发球。重排按稳定 ID 找回本关，删除当前 ID 会提示错误并保留原局。
5. 实射核对通道、球数、奖励路线与危险线余量。策划通关或失败后可「重测本关」或「返回选关」。要检查真实成长，直接打开正式模式，从第 1 关按实际所得奖励推进。

正式模式在暂停菜单选择「重载并重开」会重新读取配置并回到第 1 关。只改 JSON 时，按以上入口重载即可继续测试。

## 策划调音与素材交接

- 源码已加入背景音乐与游戏内音量设置（提交 `bc485b4`）：标题页和暂停菜单可通过「设置」分别调节「背景音乐」和「音效音量」，即时生效，点「完成」保存。**构建 23 包内没有这一功能**，下次构建随包生效。
- 源码内的背景音乐为 Cleyton Kauffman 的《Exploration Theme》，随原素材标注 CC0（同上，构建 23 包内无）。胜利音效采用团队提供的 `Win sound.wav`，失败采用 cabled_mess 的 CC0 音效。胜负两条均经响度调整与格式转换。[Lose_C_03 原始页面](https://freesound.org/people/cabled_mess/sounds/350984/)

- 工作台「音效」页支持逐槽试听、音量、静音、换 WAV 和恢复默认。换素材保留该槽音量与静音。独立导出 `audio.json` 到同一个 `Config`，在策划测试暂停菜单点「重载音效」，核对版本后继续当前局。删除 `audio.json` 后再次重载可恢复内置。
- 交接音效时记录槽位、源文件名、来源、作者、许可和加工步骤。已提交的基线出处见[首批音效素材来源](../成长版/首批音效素材来源.md)。本机的中期版目录另存 `音效替换记录.md`、`矿石轻乐音试听包计划.md` 和独立试听包。候选接入、包内版本和主观听感分别确认。
- 画面维护沿用三组矿洞、断续岩壁、切面矿石和现有 UI。背景与透明前景按组交付同画布，方块底图保留透明边缘。先保存原图和加工对照，再检查运行画面里的 HUD、球路、数字、徽记和遮挡。出处见[原美术素材来源](../成长版/美术素材来源清单.md)与[后六关素材记录](../中期版/构建23交付说明.md)。
