# 水晶矿洞 · 产品与玩法

游戏名：**Lucky Break**（中文工作名「水晶矿洞」）。产品名与窗口／APP 名取 `Lucky Break`，标题页使用美术提供的整屏键图 `Assets/Holedown/Art/Theme/title_key_art.png`（已含英文标识），因此不再绘制文字标题与单独图标。

最终版文档以 Windows 构建 23 为交付基线。玩家从矿洞上方瞄准并发射一串小球，利用反弹击碎方块。九关串联，每关击碎目标并完成该轮即可通关。

## 玩家流程

| 操作 | 输入 |
|---|---|
| 开始 | 点击「开始游戏」进入第 1 关 |
| 瞄准与发射 | 移动鼠标瞄准，在棋盘内按左键发射一轮 |
| 主动召回 | 空格或棋盘下方的「召回」 |
| 暂停与继续 | Esc 或「暂停」打开菜单，点击「继续游戏」恢复 |

切出窗口会自动暂停。返回窗口后先激活窗口，再显式继续。每次发射需要一次新按下，长按、点击 UI 或舞台两侧留边都不会发射。

## 回合、胜负与成长

1. 发射中的球全部收回且待发队列清空后，统一结算。等待超时会自动召回。
2. 结算优先判断目标是否已击碎。目标已碎则通关，普通关由玩家点击「进入下一关」，第 9 关显示「全程通关」。
3. 目标仍在时，存量方块上移一格并补入下一行。推进后任一方块最高占格到达 `row 8` 即失败。失败可重试本关。
4. 同一轮的球越打越快：首球按基础速度出手，约 10 秒升到 2 倍（基础 12 时 0／5／10 秒为 12／18／24），同轮后发的球直接从当前倍率出手；换轮、重试、切关都回到 1 倍。暂停会冻结这个加速，继续后接着走。速度上限受物理限速约束，基础值越大越早封顶。
5. 击碎奖励块会累加本次暂存球数。通关时确认奖励，从下一关起加到每轮球数。跨主题也继续累计。前两关与第 9 关没有奖励块，收齐全部奖励时入关球数从 12 升到 80。失败重试沿用原入关球数并清除本次暂存奖励。重新开始全程会清空累计成长。

初始棋盘为 8 列 × 8 行，支持方形 `1×1`、横形 `2×1`、竖形 `1×2`。竖块从锚点向上占两行，只在初始布局使用。补行可为空，每关恰有一个目标且位于最后一条补行。目标与奖励互斥。非最终关可有多个正整数加球奖励，`+3`、`+5`、`+8`、`+10` 为工作台快捷值。第 9 关没有奖励块。

## UI 与场景表现

- 正式中文 UI 覆盖开始、HUD、暂停、通关、失败、全程通关和配置错误。开始页以中文标题与主按钮为中心，Logo 作辅助徽章。深蓝与蓝灰构成面板，象牙白标示主要操作，橙金强调奖励。
- HUD 主数字为每轮总球数，左侧显示关卡和轮次，右上为暂停。仅有待确认奖励时显示「下关 +N 球」。召回始终在棋盘下方，当前不可用时置灰。策划测试额外显示在场球、待发球、补行进度、运行状态和配置版本。
- 矿洞使用竖版等比舞台，横屏两侧留边。三组各有背景、透明原位前景和普通、奖励、目标各三形底图。普通块沿用各组色调，奖励为橙金，目标为青绿。数字、徽记和裂痕由程序叠加。
- 场地底部的细接触线提示实际反弹位置。待上场区只显示真实下一排的灰蓝轮廓，向下淡出。推进时从预告位置连续升入第 0 行，落定才显示本组贴图、数字与徽记。初始方块直接出现在规则位置。
- 前景只覆盖岩石与水晶的实际轮廓。靠边方块、数字和小球可短暂被遮挡，玫红组右下大金晶也按此规则。HUD、召回与主要球路保持可读。
- 每轮首球触发金环轻脉冲，小球带短拖尾。命中闪白、轻重裂痕、碎片、奖励飘字、奖励数字轻弹和弹层短过渡提供状态反馈。
