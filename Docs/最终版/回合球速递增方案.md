# 水晶矿洞 · 回合球速递增方案

2026-11-10 已确认，待实施。目标是在**一轮之内**让球越打越快，让后半轮能压到更深的方块，同时不改回合、奖励、结算与碰撞规则。

## 当前状态

- `BallActor` 在出手时把 `GameSettings.ballSpeed` 存成固定值，每个 `FixedUpdate` 用 `velocity.normalized * speed` 把速度钉回该值，所以同一轮所有球、整轮都是同一个速度。
- 拖尾时间按固定速度换算（`直径 × trailDiameters / speed`），速度变化后需要跟着算。
- 发射间隔 0.07 秒、自动召回 30 秒、暂停冻结、召回与结算语义已由 `GameFlowController` 与 `GameSession` 管好，本轮不改。

## 规则

1. **起点**：每轮第一颗球**实际出手**的那一刻记下共享的缩放游戏时间（`Time.time`，受 `Time.timeScale` 影响，暂停即冻结），作为该轮起点。
2. **同轮后发球**：同一轮里后出手的球不再从 1 倍开始，而是从当前倍率直接出手，和在场球保持同速。
3. **每物理步应用**：`BallActor` 每个 `FixedUpdate` 沿当前方向重新赋速度：

   ```
   elapsed  = Time.time - 本轮起点
   t        = Clamp01(elapsed / 时长)
   倍率     = 1 + t                // 1 → 2
   期望速度 = 基础球速 × 倍率
   实际速度 = min(物理速度上限, 期望速度)
   ```

4. **数值**（基础 12、时长 10 秒）：0 秒 12、5 秒 18、10 秒 24，之后封顶 2 倍（24）。
5. **跨轮**：下一轮从 1 倍重新开始；重试、切关、重载同样重置。
6. **暂停**：暂停把 `Time.timeScale` 置 0，`Time.time` 停走，倍率随之冻结；继续后从冻结处延续，不会补算暂停时长。
7. **上限与安全**：倍率上限 2；基础球速先按 `物理速度上限 / 2` 安全封顶，避免旧配置里的极端 `ballSpeed` 溢出。当前 2D 物理速度上限取 **100**，即基础值最大 50、满速 100。加载旧 `settings.json` 时不拒绝其 `ballSpeed`，只在运行时按上述封顶。
8. **不变项**：`CollisionDetectionMode2D.Continuous`、反弹（`Bounce.physicsMaterial2D`，friction 0 / bounciness 1）、命中判定、返回（越界或停滞回收）与拖尾存在性都不变；只有速度数值随时间变化。

## 配置

- `GameSettings` 增加 `[Min(0.01f)] public float ballSpeedRampSeconds = 10f;`，Inspector 可调，进 `Validate()` 的正数校验。
- **不改** `settings.json` 与策划工作台的格式：时长走默认值 10 秒，玩家配置仍只有原来的七个字段，`launchInterval`、自动召回与结算都不动。
- 需要换时长时改 Inspector 或新增配置字段都在后续单独立项，本版不加 JSON 键。

## 实现要点

| 位置 | 改动 |
|---|---|
| `GameFlowController.LaunchVolley` | 首球真正出手时记录 `volleyStartTime = Time.time`（同一轮只记一次），后发球传入同一时间戳。 |
| `BallActor.Launch(...)` | 接收本轮起点与时长，保存基础速度（已按上限封顶）；出手速度为本轮当前的期望速度。 |
| `BallActor.FixedUpdate` | 每个物理步按上式重算速度并赋值；拖尾 `trail.time` 随当前速度换算，保持视觉长度。 |
| `GameSettings` | 新增 `ballSpeedRampSeconds`，默认 10，正数校验。 |

拖尾、金环脉冲、命中特效、音效触发都不改。

## 验收

| 项目 | 口径 |
|---|---|
| 首球与后发球 | 同一轮首球按 1 倍出手，后发球按当时倍率出手，两者在场速度一致 |
| 时间曲线 | 基础 12、时长 10 秒时，0 秒 12、5 秒 18、10 秒 24，之后保持 24 |
| 暂停与恢复 | 暂停期间速度与倍率冻结（`Time.timeScale = 0`），继续后从冻结处延续 |
| 换轮重置 | 结算进下一轮、重试、切关、重载后从 1 倍开始 |
| 上限 | 基础值超过一半上限时被安全封顶，实际速度不超过 100 |
| 满速碰撞 | 24 与 2 倍封顶速度下：墙壁、底边反弹正常，窄缝里的横块与竖块仍能命中并正常返回 |
| 既有语义 | 发射间隔、自动召回、召回、结算、奖励与失败条件不变 |

Windows 与 Editor 都要看实际画面：首球、5 秒、10 秒三个时点的球速与拖尾长度，暂停前后位置冻结与恢复。
