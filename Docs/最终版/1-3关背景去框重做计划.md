# 1–3 关背景去框重做计划（硬边像素版）

## Context
用户反馈当前游戏背景“边缘有模糊感”。排查结论：不是导入、透明混合或渲染后处理，而是后期脚本把原始硬边像素画处理软了。原始背景在 Git `afb2d78`（LFS）中仍是清晰的像素画，带亮蓝外框和顶部牌匾；当前 `background_game.png` 经过调色板量化、`ModeFilter(5)`、`cv2.inpaint(TELEA)` 和 34px 渐变压暗后，洞壁、岩石和画布外沿都变柔。

本计划按以下取舍执行：外沿和洞壁都要修；从 Git 原图重做去框；硬像素邻接填充；保留当前偏暗/安静的边缘色调；保持 941×1672；同时修正工具脚本；本次只处理 1–3 关背景。

## 排查依据
- 背景导入：Point、无 mip、无压缩；alpha 全 255，无半透明边缘。
- 渲染：URP MSAA 1（关闭）、相机 AA 0、后处理 0、Render Scale 1，没有全屏模糊。
- `Tools/PolishExistingTheme.py` 的 `background()` 对边缘 130px 区域做调色板量化，`palette()` 内含 **ModeFilter(5)**，会抹平像素边缘。
- `Tools/RemoveStageFrame.py` 用 **cv2.inpaint(TELEA)** 去框，再对四周做 **34px 渐变压暗**；这是外沿发柔的直接原因。
- 941→540/720 的非整数缩放会带来像素不均，但不是“糊”的主因。
- 截图 y≈0 附近的横向细线是另一个独立问题（召回底衬/接缝），不在本次范围；修完背景后单独查。

## 目标
- 保留原图构图、水晶位置、底部岩群和中间渐变；保持当前偏暗的边缘色调。
- 去掉亮蓝外框、顶部牌匾及烘焙阴影，不留下矩形硬边、渐变羽化或补丁接缝。
- 洞壁、岩石、水晶恢复硬边像素；外沿以真实岩壁像素硬收边，不做 34px 羽化。
- 输出 941×1672 RGBA（alpha 255），沿用现有 `.meta/GUID` 和导入设置；不改其他资源。
- 中间区域保持当前/原图的安静渐变，不额外加装饰、噪点或新框。

## 实施步骤

### 1. 取回原始图
- 从 Git LFS 读取 `afb2d78:Assets/Holedown/Art/Theme/background_game.png`，复用 `Tools/PolishExistingTheme.py` 的 `source()` 或等价 LFS 读取逻辑。
- 核对尺寸 941×1672、RGB，确认是带框原始图；不要拿当前已糊的 PNG 当输入。

### 2. 建立紧致的框/牌匾遮罩
- 从原图实测亮框厚度、内亮线、顶部牌匾多边形，输出遮罩叠加预览。
- 不要沿用旧脚本的 44/100/42px 大矩形；只遮真正的框、牌匾及其烘焙阴影，保护贴边水晶尖端和岩石轮廓。
- 逐边、逐角检查遮罩；宁可多迭代几次，也不要误删洞穴岩壁。

### 3. 保留当前暗调，但去掉平滑
- 复用当前 `PolishExistingTheme.background()` 的压暗系数和调色板：岩石乘 `[.88,.93,.94]`，水晶乘 `.78` 再加 `[4,9,12]`；复用 ROCK/TEAL 调色板。
- 给 `palette()` 增加 `smooth=False` 路径；**背景不使用 ModeFilter(5)**。其他组（方块/细节/Logo）保持原逻辑，避免扩大改动。
- 中间渐变保持原样；只对边缘框区域应用压暗和调色板。

### 4. 硬像素邻接填充
- 对遮罩内像素，用**最近的非遮罩源像素**填充（距离变换/最近邻复制），不要颜色平均、不要 Telea inpaint、不要羽化。
- 外框向内取洞穴岩壁像素；顶部牌匾向下方/两侧取洞穴顶壁；角部取最近内部像素。
- 填充后逐边检查接缝；若出现直线或重复纹理，用少量手工像素修补，仍保持硬边，不引入模糊。
- 不做旧脚本的 34px 渐变压暗；外沿就是新洞穴岩壁与画面边界的硬像素接边。

### 5. 脚本与流程
- 更新 `Tools/PolishExistingTheme.py`：为背景增加无 ModeFilter 的调色板路径。
- 重写或替换 `Tools/RemoveStageFrame.py`：读取原图、应用暗调、紧致遮罩、最近邻填充、输出预览；`--apply` 才覆盖 `background_game.png`，不碰 `.meta`。
- 默认运行只写预览，不覆盖项目资源；预览通过后再 apply。
- 记录可复现步骤，保证以后重跑不会重新引入 blur；不影响其他资源组。

### 6. 测试
- 新增 EditMode `BackgroundEdgeTests`：
  - 941×1672、alpha 全 255。
  - 外沿区域不含原亮框颜色；牌匾区域不含原牌匾颜色。
  - 外沿不是旧 34px 渐变的统一外色；边缘像素来自原图调色板，没有新增混合色。
  - 中间抽样像素与当前背景一致（保留暗调/渐变）。
- 现有背景/主题/UI 测试保持通过；不改 4–6、7–9、方块、字体的测试。

## 验证
- 预览：原图/新图全图对比；上、下、左、右、四角 1:1 局部放大；新图在 540×960、720×1280、1080×2400 的离线合成。
- 检查：无亮框、牌匾、金环残留；洞壁/岩石硬边；无羽化、接缝、重复纹理；水晶位置和暗调保持；中间渐变不变；与 4–6 的硬边像素风格并排看不突兀。
- 通过后 `--apply` 覆盖 `background_game.png`，GUID 不变；用当前 Unity 6000.4.3f1 采集实际 Game 画面截图，不只交预览图。
- 运行相关 EditMode/PlayMode 回归；不新开同项目 batchmode；不自动提交/推送。
- 单独记录 y≈0 横线问题，不在本次修复中顺手改 UI。
