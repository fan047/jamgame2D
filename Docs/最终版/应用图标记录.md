# 应用图标记录

## 选定方案

图标为**发射用金球**：游戏里玩家打出去的那颗球，直接取 `Assets/Holedown/Art/Theme/ball.png` 原图，保留自己的台阶式轮廓、不等宽描边、顶部白色高光与亮面切分，压在深靛蓝洞穴底色上。球占画面约 74%。

先做过一版水晶图标（键图中央那颗橙金水晶），现已替换。当时担心金球“过于通用”，但明确要发射的球之后，以球的辨识度为先：它是游戏里唯一一直存在的亮点，与玩家第一眼看到的东西一致。

## 素材

- 源：`Assets/Holedown/Art/Theme/ball.png`（257×257 RGBA，与游戏内同款），按原样使用。
- 处理：只按 alpha 裁到可见边界并补成正方形（避免缩放时压成椭圆），颜色与透明度不改。
- 试过把轮廓重建为平滑圆（等宽描边、抗锯齿、球面明暗），脚本保留为 `--round`，但没有采用：台阶边缘才是这张像素图的手感。
- 背景：深靛蓝径向渐变，中心微暖，与键图同调。
- 工具：`Tools/BuildAppIcon.py`（Pillow／NumPy）。默认只写 `Library/Locus/tmp/icon`，`--apply` 才写入正式资源。

产物在 `Assets/Holedown/Art/Branding/Icon`：

| 文件 | 用途 |
|---|---|
| `LuckyBreakIcon.png` | 1024 主图 |
| `LuckyBreakIcon{192,144,96,72,48,36}.png` | Android 旧式图标各档 |
| `LuckyBreakIconFg{432,324,216,162,108,81}.png` | Android 自适应前景（透明，球在中央 66% 安全区） |
| `LuckyBreakIconBg{...}.png` | Android 自适应背景（深靛蓝，中心微暖） |
| `LuckyBreakIconWin{1024…16}.png` | Windows 播放器图标 |

导入统一为 Default、无 mipmap、无压缩、最大 1024；仅前景两张开 alphaIsTransparency。

## 接入结果

- Android：Legacy、Round、Adaptive 各 6 档全部指到对应尺寸的贴图，`SetPlatformIcons` 后逐槽回读校验，0 处缺失。自适应前景与背景按档一对一配对，构建时不会触发图标缩放。
- Windows：`Standalone` 8 档（1024…16）全部写入。
- 已确认 `ProjectSettings/ProjectSettings.asset` 里存的是图标贴图的 GUID，不只是编辑器内存状态。

## 预览

`Library/Locus/tmp/icon/`：`icon-master.png`（1024 主图）、`icon-sheet.png`（各档尺寸与三种裁切）、`launcher-mock.png`（桌面实景）、`ball-walls.png`（深色／浅色壁纸对比）。
