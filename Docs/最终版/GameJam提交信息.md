## 作品信息

- **作品名称**：Lucky Break
- **一句话介绍**：瞄准矿洞发射弹球，借岩壁反弹击碎方块；击碎青色水晶推进，收集橙色奖励让下一关球更多。
- **游戏方向标签**：动作、解谜（若只能选一个，选「解谜」）

### 作品说明（可直接粘贴）

```text
《Lucky Break》是一款竖屏弹球解谜游戏。你从矿洞顶部瞄准并发射一轮小球，球在岩壁与方块之间反弹，削减方块血量；球全部回收后棋盘整体上移，新的一排从底部升入。

· 普通灰蓝岩块是障碍，击碎可以腾出空间；青色水晶是目标块，击碎它才能推进本关；橙色上箭头是奖励块，击碎后会在通关时结算，从下一关起增加每轮球数，形成跨关成长。
· 方块越过危险线即失败，可立即重试本关。方块有轻/重两档裂痕；血量数字、奖励数值和裂痕都由程序叠加，不烘焙在图片里。
· 共 9 关，分青晶、紫晶、玫红金晶三组矿洞；每关击碎目标并完成当前轮次即可通关。

运行平台：Android 7.0（API 25）及以上，arm64 手机，竖屏。
启动说明：解压后安装 CrystalMinePlaytest.apk（应用名显示为 Lucky Break），打开后点「开始游戏」。已安装旧 Demo 可直接覆盖安装；APK 文件名和包名是早期命名，不影响游玩。
操作：拖动屏幕瞄准，松手发射；点击底部「召回」提前回收；右上角「暂停」；标题页或暂停菜单的「设置」可调音量。
```

### 原稿需要更正的三处

- “普通灰蓝岩块提供推进” → 普通块是障碍，目标是青色水晶。
- “底部亮起的方块” → 现在是灰蓝轮廓的下一排预告。
- “每轮多发射 3 或 5 颗” → 实际奖励不只 3/5，建议写成“按奖励增加每轮球数”。
