# Lucky Break 标题页终版打磨计划

## Context
用户要求按终版标准打磨标题页。Build 23 的标题截图（2026-11-10 17:17）已过期：工作区 22:26 新加了 `Assets/Holedown/Art/Theme/title_key_art.png`（942×1670，未跟踪），已挂到 `StartPanel`；`VisualTheme.logoContainsTitle=1`，旧的文字标题和独立小 Logo 被隐藏。当前标题页实际是：整屏 “Lucky Break” 键图 + 奶白开始按钮 + 操作提示。

本计划基于四轮取舍：终版提交；只保留英文品牌；保留键图、UI 像素化；竖屏舞台 + 洞穴渐变/暗角；按钮上移到 Logo 下方约 40%，提示单行放底部约 90%；提示 28–30 号 Noto + 暗色像素底；按平台切换文案；水晶呼吸光 + 3 颗漂浮粒子；复用共享象牙按钮 + 像素描边；右上角复用现有音频设置；淡出 + 轻微暖色闪光；安卓锁竖屏；触控热区扩大并处理安全区。

## 现状问题
- 键图分区：Logo 约 14–35%，水晶约 48–58%，水面倒影约 74–96%。
- 开始按钮当前在约 77%，正好压在最亮的倒影上，像贴上去的 UI；提示在 86%，24.37 号偏小。
- 安卓当前默认 `LandscapeRight`，但游戏是竖屏舞台；横屏会让标题只占中间约 405px，按钮和文字都偏小。
- `AudioSettingsView.Start()` 已在标题页右上角生成“设置”按钮（194,-51，96×42）并打开音量面板，可复用，不新建一套。

## 目标布局
- **键图满屏**：保持 `StartPanel` 的 Image 全屏拉伸，不裁切、不改变 942×1670 比例；不重新启用隐藏的文字标题/小 Logo。
- **开始按钮**：上移到 Logo 下方暗区，锚点约 `(0, -668)`（1670 画布约 40%），保持约 390×97 设计尺寸；复用 `MineUIStyle.Button(start, primary:true)` 的象牙色斜角按钮，外加 2px 深色描边/底部阴影；触控热区至少 56dp（可在按钮外扩一圈透明命中区）。
- **操作提示**：移到约 90%（锚点约 `(0, -1503)`），单行；暗色像素底板（`CutCornerImage` + `MineUIStyle.Panel`，1px 深色边），文字 28–30 号 Noto，保持可读。
- **文案**：按平台切换。安卓/触屏：“拖动瞄准 · 松手发射 · 点击召回”；桌面鼠标：“移动鼠标瞄准 · 左键发射 · 空格召回 · Esc 暂停”。用 `PlayerInputController.UsesTouch` 或 `Application.isMobilePlatform` 判断。
- **音频入口**：复用 `AudioSettingsView` 的标题页按钮与音量面板；标签由“设置”改为“声音”，放在安全区内。
- **两侧与上下暗边**：新增世界空间渐变/暗角背板，位于背景之后，覆盖相机视野；颜色取自键图边缘的深蓝/靛色。桌面横屏填两侧，超长手机填上下；不拉伸键图。标题页显示，进入游戏后可关闭，避免改变局内画面。
- **UI 像素化**：复用 `MineUIStyle` 与 `UIButtonIvory`，只加描边/阴影/像素底板，不新做按钮美术；中文仍用现有 Noto，避免像素中文字形与授权风险。
- **动效**：水晶处叠加柔光呼吸（约 2.5–3 秒一循环，透明度小幅变化）；3 颗小粒子缓慢漂浮；按钮保留 `ButtonPressMotion` 的悬停/按下反馈；不做水面动画。
- **转场**：保留现有 `PanelTransition` 的 0.14 秒淡出 + 0.96 缩放，开始时叠加一次很轻的暖色全屏闪光（约 0.2 秒）。
- **安全区**：键图允许铺到刘海/圆角下；按钮、提示、音频按钮放在一个 `TitleContent` 安全区内，按 `Screen.safeArea` 做上下/左右内缩，避免被手势条或摄像头挡住。

## 实现步骤
1. **场景布局**（`Assets/Scenes/SampleScene.unity`）
   - 在 `StartPanel` 下增加 `TitleContent`（全屏拉伸，仅承载交互/文字），把 `Start`、`Controls`、`AudioSettingsButton` 移入；键图 Image 仍留在 `StartPanel` 全屏。
   - 调整 `Start` 锚点到约 `(0,-668)`、`Controls` 到约 `(0,-1503)`；给提示加 `CutCornerImage` 暗底板。
   - 新增水晶柔光 Image（暖橙/金色，低透明度，叠加在水晶上方）、3 个粒子 Image；不改变键图资源。
   - 不启用当前隐藏的 `Title`/`Logo` 对象。
2. **标题逻辑**（`Assets/Holedown/Scripts/Runtime/StartScreenView.cs` 或新增 `TitleScreenView.cs`）
   - 平台文案切换；`TitleContent` 安全区内缩；按钮热区扩大；开始转场的暖色闪光；标题页显示/隐藏暗边背板。
   - 复用 `PanelTransition`；不新增 UI 框架。
3. **音频入口**（`Assets/Holedown/Scripts/Runtime/AudioSettingsView.cs`）
   - 标题页按钮标签改为“声音”，挂到安全区；面板逻辑与音量滑杆保持不变。
4. **暗边背板**（新增 `TitleBackdrop.cs` + 渐变材质/纹理）
   - 世界空间 quad 放在背景之后，按相机视野铺满；颜色取自键图边缘；标题页启用，进入游戏关闭。
5. **安卓方向**（`ProjectSettings/ProjectSettings.asset`）
   - 仅改移动端方向字段：`defaultScreenOrientation` 设为 Portrait，关闭横屏自动旋转；不要覆盖用户其他未提交设置。
6. **像素描边/底板**
   - 优先复用 `MineUIStyle`、`CutCornerImage`、`UIButtonIvory`；只有在现有资源无法做出 2px 描边时才新增一张 9-slice 小图。

## 测试与验收
- **布局**：720×1280、1080×2400（超长屏）、1280×720（桌面横屏）三种尺寸截图；按钮不压水晶/倒影，提示不被手势条/圆角遮住，音频按钮在安全区内。
- **交互**：触屏点按钮开始；扩大热区不误触其他 UI；桌面鼠标点击开始；点击开始不会误发第一球（保留 `StartClickInputTests`）。
- **音频**：标题页“声音”按钮打开现有音量面板，滑杆与返回正常；关闭后焦点/交互恢复。
- **动效/转场**：柔光与粒子不抢焦点；开始转场无闪烁、无输入穿透。
- **方向**：安卓锁竖屏；桌面窗口缩放/留边不变。
- **回归**：暂停/召回/设置、标题页与局内切换、`FormalUIAcceptanceTests` 不回归。
- 复用当前打开的 Unity 6000.4.3f1 编辑器，不再开同项目 batchmode；以实际 Game 画面截图验收，不以网页拼图代替。
- 未完成的验证明确报告，不声称已完成。
