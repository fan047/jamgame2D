|---|---|
| [产品与内容](中期版/产品与内容.md) | 全员。九关玩法与奖励、视觉范围、策划工具和完成条件。 |
| [技术方案与验收](中期版/技术方案与验收.md) | 程序或接手 agent。现有架构、配置兼容、音效调节实现、逐项自测与提交。 |
