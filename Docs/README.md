## 文档归档约定

- 新读者从项目首页和本索引进入；文档按现有 MVP、成长版阶段归档，不因整理而改写历史记录。
- 设计与技术方案描述要求或计划；交付说明记录实现、验证与边界，两者不可混同。
- 发布新交付说明时更新本索引的最新入口，保留旧文档供追溯。
- 文档移动前检查 Markdown 相对链接；Unity 资源、外置配置和共享测试样本不跟随文档随意移动。
- 构建包继续按 `Builds/01`、`Builds/02` 等独立编号保留，不覆盖历史构建。
