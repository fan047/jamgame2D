# 项目文档

**后续开发与团队交接以最终版文档为准。** 当前交付基线为 Windows 构建 23，包含九关、三组矿洞、正式中文 UI、待上场预告和离线策划工作台；另有 Android 试玩包 01。

| 文档 | 阅读对象与用途 |
|---|---|
| [产品与玩法](最终版/产品与玩法.md) | 全员。玩家流程、胜负、加球成长、九关数据与视觉规则。 |
| [技术与验收](最终版/技术与验收.md) | 程序与接手 agent。架构、配置、分组主题、音效契约和逐项自测提交。 |
| [交付与操作](最终版/交付与操作.md) | 策划、美术和测试。Windows 交付入口、工作台操作、素材交接与待复核范围。 |
| [回合球速递增方案](最终版/回合球速递增方案.md) | 全员。每轮从基础球速线性升到 2 倍，按物理步应用、暂停冻结与验收口径。 |
| [Android 真机试玩方案](最终版/Android真机试玩方案.md) | 程序与测试。Android Playtest 构建、随包配置、触控安全区与真机验收。 |
