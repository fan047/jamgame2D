## 占位界面

沿用 World Space uGUI、中文 TMP 与既有命令／输入门禁，未更换正式 UI 素材。

- 开始页：矿洞背景与 Logo、金色「开始游戏」、一行操作提示。
- 正式 HUD：只显示关卡、每轮球数、轮次与待确认奖励；诊断信息仅策划测试显示。
- 底部「召回」居中，不可用时置灰；配置重载已从局内移入暂停菜单。
- 暂停与结算改为居中遮罩，收起局内控件并拦截底层点击。
- 结算：普通关显示已获奖励与下一关球数，失败、全程通关、策划测试与配置错误各保留对应操作。

## 音效

- 8 条音效各自可试听、调音量（0–150%）、静音、换 WAV、恢复默认；全关共用一份配置。
- 换素材保留该条音量与静音；普通块与目标块共用碎裂设置。
- 任何可解码 WAV 会转换为 48 kHz、16-bit 单声道 PCM，最长 3 秒；试听与导出使用同一份转换数据。无效或超长输入说明原因并保留原素材。
- 新增可选 `audio.json` v1，与球参、关卡文件分开导入导出；缺项用默认，未知槽位、非法字段或损坏 WAV 报槽位错误。
- 启动时读取该文件；坏文件回退内置音效并在界面提示，关卡照常加载，音效错误与关卡配置错误相互独立。
- 策划测试暂停菜单新增「重载音效」：先校验再切换，失败保留上一版，删除文件后重载恢复内置；只清理旧播放与自建片段，棋盘、奖励、回合、球数、在途球和暂停状态都保留。正式模式不显示该按钮。
