# 矿洞边缘前景遮挡

给底部和左右边缘增加透明前景，让边缘方块像嵌在岩石与水晶后面。采用静态遮挡，补行继续按现有回合规则进入第 0 行。

## 画面约定

- 从现有矿洞原图提取岩石与水晶，重新贴近实际棋盘边界摆放。底部前景向画框下缘衔接，左右装饰向外连接原边框，中央保持透明。
- 默认盖住边缘方块约 **0.12 世界单位**，约为单格块可见宽高的 13%。第 0 行下沿被轻微遮住，补行形状仍然可辨。
- 前景遮住方块底图和裂痕。血量、目标／奖励标记、小球和击碎反馈显示在前景上方。
- 暂停、结算和召回按钮等 UI 位于前景上方。

## 接入方式

- 新增独立透明前景 Sprite，沿用共享舞台的尺寸和对齐方式。使用原画边缘素材制作，与背景接缝处检查颜色、比例和像素边缘。
- `VisualTheme` 增加通用前景及三组可选覆盖引用。`SceneVisuals` 随关卡背景同步选图，未配置分组前景时使用通用前景。
- 前景放在现有排序的 **Order 2**，位于裂痕的 Order 1 与文字的 Order 3 之间。
- 前景作为纯显示对象。方块生成、占格、碰撞和棋盘推进继续使用现有坐标。前景覆盖范围以底部及最外侧一列的外沿为限。

## 验收与交付

- 在实际 Game 画面检查初始底排、补行出现和下一轮上移后的遮挡，确认底排与装饰衔接，数字及身份标记清楚。
- 覆盖普通、奖励、目标块，以及初始竖块和横块。贴边反弹时球保持可见，受击缩放与碎裂反馈正常。
- 验证 540×960、1280×720 和窗口缩放，检查前景、背景、棋盘与 UI 对齐，并覆盖三组背景切换及前景回退。
- 每项独立改动自测通过后提交一次 Git，验收结果并入中期版文档和下一编号构建。
