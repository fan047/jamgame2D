## 二、标准版作品说明（约 400 字，适合表单直接粘贴）

```text
《水晶矿洞》（Lucky Break）是一款 2D 像素风弹球游戏，玩法受 holedown 启发：发射一串弹球，在矿洞中反弹打碎下压的方块；击碎青色目标块推进关卡，击碎橙色奖励块可在下一关获得 3～5 颗额外球；九关分青晶、紫晶、玫红金晶三组主题。

运行平台：Windows 10/11（64 位）与 Android 7.0+（arm64 竖屏）；源码需 Unity 6000.4.3f1 与 Git LFS。

启动方式：Windows 解压后双击 HoledownGrowth.exe（保留同目录 Data、Config）；Android 允许安装未知来源后安装 APK；源码用 Unity 打开 Assets/Scenes/SampleScene.unity 进入 Play。

操作：鼠标瞄准＋左键发射，空格召回，Esc 暂停；手机为触控，界面提供召回、暂停与音量设置。

完成内容：九关完整流程与胜负结算、三组矿洞主题与全中文 UI、正式像素美术（三形三身份方块、两档裂痕、徽记、发射器、标题徽章）、八类 CC0 音效、离线关卡／音效策划工作台，以及按编号归档的 Windows 与 Android 包。
```

## 三、完整版作品说明（约 850 字）

```text
《水晶矿洞》（Lucky Break）是一款 2D 像素风弹球游戏，玩法受 holedown 启发：瞄准并发射一串弹球，让球在矿洞中反弹，打碎层层下压的方块，挖得越深越接近过关。

【运行平台】
· Windows 10/11（64 位）：完整九关试玩包。
· Android 7.0 及以上（arm64）：竖屏触控试玩包。
· 也可以源码运行：Unity 6000.4.3f1（Unity 6）＋ Git LFS。

【启动方式】
· Windows：解压压缩包后直接双击 HoledownGrowth.exe。请保留同目录的 Data 与 Config 文件夹，不要只拷贝 exe。想直接跳到指定关卡，可运行同目录的「策划测试.cmd」。
· Android：把 APK 传到手机，允许「安装未知来源应用」后安装。全程竖屏，触控操作。
· 源码：先 git lfs pull 拉取图片、音频和字体，用 Unity Hub 打开仓库根目录，打开 Assets/Scenes/SampleScene.unity，进入 Play Mode，点击「开始游戏」。

【操作】
· 鼠标移动瞄准，在棋盘范围内按左键发射一轮；空格或「召回」按钮收回在场弹球；Esc 或「暂停」按钮暂停。
· 手机端为触控瞄准与发射，界面提供召回、暂停与音量设置。

【玩法与主题】
· 每轮发射固定数量的球，球在矿洞中反弹并削减方块血量；底部亮起的方块是下一排预告，球全部回收后棋盘整体上移，新的一排从底部升入。
· 普通灰蓝岩块提供推进；青色水晶块是目标块，击碎它才能让本关推进；橙色上箭头块是奖励块，击碎后本关通关时确认，从下一关起每轮多发射 3 或 5 颗球，形成跨关成长。
· 方块越过危险线即失败，可以立即重试本关；伤害分两档裂痕，血量数字与 +3/+5 都由程序显示，不烘焙在图片里。
· 九关分为青晶、紫晶、玫红金晶三组矿洞主题，画面为深蓝矿洞、灰蓝岩壁、青色水晶、金色弹球与金环发射器的像素画风，标题使用无字矿洞水晶徽章；界面为全中文。

【完成内容】
· 九关完整流程：瞄准、连发、手动召回、补行与待上场区、危险线、胜负结算、失败重试、全程通关。
· 正式美术：三组矿洞背景与透明前景、三种形状与三种身份的方块底图、目标／奖励徽记、两档裂痕、弹球、金环发射器、碎片与星光、标题徽章，均由原始美术本地提取／修复并逐项记录来源。
· 八类音效（发射、受击、碎裂、奖励、过关、失败、召回、确认），来源为 CC0 授权素材并经裁剪与响度对齐；源码另含背景音乐与音量设置。
· 全中文 UI：标题页、暂停／失焦、关卡进度、结算与重试，支持 540×960 到 1280×720 的竖横屏自适应。
· 离线策划工作台：无需服务器，可导入关卡配置、整关总览、批量改血量与奖励、逐槽试听与替换音效，并导出 JSON 供游戏重载。
· 工程内保留 EditMode／PlayMode 自动化测试与工作台 Node 测试，构建按编号归档、不覆盖旧包。

【补充说明】
· 运行包内关卡与球参随包分发，无需额外配置；Windows 包内另含策划工作台与校验文件。
· 美术素材由团队提供的两张原始画稿本地处理，音效与音乐均为 CC0 或团队素材，出处记录在 Docs/ 下；未使用付费生成服务。
```

## 五、粘贴前请按实际提交物替换两处

| 位置 | 若提交 Windows 包 | 若提交 Android 包 |
|---|---|---|
| 「运行平台」 | 只保留 Windows 一行，删掉 Android | 只保留 Android 一行 |
| 「启动方式」 | 写明压缩包名 `Holedown-LateStageGroups-Windows.zip` | 写明 APK 名 `CrystalMinePlaytest.apk` |

已核对的事实与差异，避免写错：

- 应用名／exe 名不统一：应用显示名 **Lucky Break**，Windows 可执行文件仍是 `HoledownGrowth.exe`，APK 文件名与包名仍是 `CrystalMinePlaytest.apk` / `com.fan047.crystalmine.playtest`（构建 23、Android Demo 02 均如此）。
- 游戏内标题是「水晶矿洞」，与英文名并存，投稿标题建议写作「水晶矿洞（Lucky Break）」。
- Windows 构建 23 **不含**背景音乐与音量设置，这两项在之后提交的源码里；Android Demo 02 说明中写明「音量设置可保存」。若提交 Windows 23，请删掉「源码另含背景音乐与音量设置」里的包内暗示。
- Android 包为 Unity 调试签名、仅 arm64、竖屏；真机帧率与手势条避让尚未实测，投稿页如需「已知问题」可补一句。
- 九关、三组主题、八类音效、离线工作台、Builds 编号归档均已从工程与交付文档核对；未在文案里写具体测试数量或通关时长，避免与最新构建不一致。
