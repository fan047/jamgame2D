## 与旧方案的差异

- 旧 `foreground_game.png` 用矩形拼接岩层 + 实色补缝，形成贯穿场地的深灰挡板，已整体替换，可复现脚本与断言一并更新。
- 整盘入场（`PlayEntry`／`entrySeconds`／`entryClearance`）与「第 0 行下缘必须被实色岩层覆盖」的旧断言已移除，未用造墙方式通过测试。

## 已知限制与待验项

- 岩石／水晶现在按真实轮廓遮住方块与数字（内容为原位像素，不会新增遮挡），因此左下、右下水晶附近的方块边缘会被压住；判定口径是「中央读数与主要球路不被遮」，若希望数字永远在装饰之上，需要单独调整 TMP 排序（当前数字排序 3）。
- 待上场区与召回按钮的纵向间距按实测文字边界取 `y=-1.05…-0.10`（`centreY=-0.55`）；换字体或改召回文案后需要复核。
- 底边接触线为新增显示对象，视觉权重低；如需更弱可改 `Game/FloorLine` 的 alpha（当前 0.40）。
- 方块边缘与 256 裂痕的非等比运行缩放、长错误正文滚动条手柄、策划选关字号量尺等问题与构建 20 相同，未在本轮处理。
- Windows 包未在本机以真实窗口点击复测暂停／重试／配置重载，界面态证据来自编辑器内运行的真实游戏。
