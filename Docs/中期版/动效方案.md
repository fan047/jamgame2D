# 中期版动效方案

以局内反馈为主，配少量按钮和弹层过渡。整体采用清爽、短促的风格，首版参数由程序在 Unity Inspector 调整，策划通过试玩反馈。

## 动效清单

以下数值作为首轮调试默认值。

| 事件 | 表现 |
|---|---|
| 棋盘推进 | 旧块与新补行一起平滑上移一格，约 **0.2 秒**，临近终点减速。新行从底部滑入，进入完成后显示数字和身份标记。 |
| 发射 | 每轮首球出手时，金环用 **0.12 秒**从原尺寸轻微放大再恢复。小球增加淡出短拖尾，长度控制在约两个球直径内。 |
| 普通受击 | 沿用现有 **0.12 秒缩放、前 0.06 秒闪白**和裂痕反馈。连续命中从原尺寸重新开始。 |
| 普通击碎 | 约 **0.3 秒**的短距离碎片飞散、减速和缩小。限制同时存在的普通碎片数量，多块同时击碎时减少新增碎片。 |
| 奖励块击碎 | 保留约 **0.6 秒**的 `+球` 飘字与局部光效，HUD 待确认奖励数字轻弹一次，约 **0.18 秒**。连续奖励合并刷新最终数值，并从原尺寸重启动效。 |
| 目标与通关 | 目标击碎时播放局部光效。本轮结束后，过关面板再用约 **0.14 秒**淡入并轻微放大至正常尺寸。 |
| 按钮与弹层 | 按钮按下时轻微缩小、释放恢复。开始、暂停、结果与错误面板共用短淡入和轻微缩放，关闭时短淡出。 |

## 棋盘推进与底部遮挡

- 增加明确的推进中状态。当前轮的球全部回收后，执行一次规则结算并播放推进。推进完成后才恢复瞄准，或显示越线失败结果。目标通关沿用本轮结算结果。
- 新行的块身和裂痕在进入期间按棋盘底线 `y=0` 裁切，数字和标记暂时隐藏。扩展现有方块表现材质，裁切与闪白分别控制。底部和两侧的静态岩石前景继续负责压住方块外沿。
- 推进期间支持暂停与失焦暂停。重试、切关和重载会取消旧推进，清理旧回调并建立一致的新局面。

## 接入与生命周期

复用现有发射、命中、奖励和结算事件，用协程驱动现有图形、碎片和 uGUI。局内动效使用游戏时间，暂停时冻结。弹层过渡使用非缩放时间，使暂停菜单可以正常打开和关闭。输入权限随界面状态立即切换，过渡动画只负责显示。

尝试重置时清理碎片、拖尾和动画，恢复金环、方块及 HUD 的原尺寸。动效参数集中在 Inspector 中配置。

## 验收与交付

- 验证连续推进、空补行、最后一条补行、目标通关和越线失败。推进中点击与长按均不提前发球，底线以下的补行内容隐藏。
- 验证推进中暂停、失焦恢复、重载和切关，旧动画无法影响新棋盘。
- 在多球连续命中和多个奖励同轮击碎时检查数字、球路、拖尾与碎片上限，确认结算只触发一次。
- 在 540×960、1280×720 及窗口缩放时检查前景、方块、飘字与 HUD 的对齐，回归既有输入、暂停和音效测试。
- 每项独立改动自测通过后提交一次 Git，结果并入中期版文档和下一编号构建。
