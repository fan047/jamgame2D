## 策划操作

1. 打开 Windows 包内的 `PlannerEditor/index.html`，用 Chrome 或 Edge 同时导入自己正在用的 `settings.json` 和 `level.json`。优先保留策划最新文件和原包备份，网页默认示例仅供起步。
2. 在第 3 关之后用「新增关」或「复制当前关」开始后六关。通过整关总览编辑初始棋盘和补行。每关补齐最后一条补行的唯一目标，再校验导出。把下载文件放回正在运行的 exe 同级 `Config`，核对文件名和 HUD 版本。
3. 双击同目录 `策划测试.cmd`，选择关卡以及基础、满前关奖励或手填球数。布局或球参数有改动时，暂停并点「重载当前关」。用实射核对路线、球数和难度。全奖预估只显示边界，发射时长提示也需用实射复核。
4. 在工作台「音效」页试听和编辑，单独导出 `audio.json` 放入同一 `Config`。在策划测试里暂停，点「重载音效」，检查面板上的音效版本后继续；坏文件会保留上一版并说明原因。把文件交给队友即可共享这次音效配置。

构建 20 的详细操作见[策划快速上手](../../Tools/PlannerEditor/快速上手.txt)。

## 美术与音效交付

- 两位美术先交第 4–6 和第 7–9 关的背景原图，各标清对应分组。参考当前 941×1672 矿洞舞台，保持约 9:16 构图、完整外框及安静的棋盘区域。标题、金环、文字和 HUD 独立放置。优先背景，方块可按余量补同风格变体。
- 游戏样片已经有背景、金环、小球、普通／奖励／目标三形底图、独立标记、轻重裂痕、无字主视觉和碎片光效。交接使用 PNG，背景不透明，其余按素材需要保留真实透明。原图保留，处理图记录来源、尺寸和加工方法。中文、球路和数字可读性作为方向稿验收条件。页面数量、按钮布局、切图数量与导出规格等方向确定后再细化。
- 程序负责资源绑定和 Windows 包验证。策划负责正式关卡、实射平衡与音效取舍。新增或替换的音效记录来源及授权，当前八条内置素材保留逐项记录。

参考 [现有游戏画面与素材验收](../成长版/正式美术样片交付说明.md)、[美术素材来源](../成长版/美术素材来源清单.md)、[UI 样例图](../成长版/UI样例/UI占位样例.png)和[首批音效素材来源](../成长版/首批音效素材来源.md)。UI 样例供了解现有功能，方向稿可自由组织。

| 音效槽位 | 触发与听感 |
|---|---|
| `volley_launch` 发射 | 每轮首球出手，一声短气流。 |
| `block_hit` 受击 | 方块受伤且还在，高频轻敲。 |
| `block_break` 碎裂 | 普通块或目标块击碎，玻璃裂响。 |
| `reward_break` 奖励 | 击碎奖励块出现 `+球` 提示，上扬拨弦音。 |
| `stage_clear` 过关 | 本轮结算为通关，明亮上行乐句。 |
| `stage_fail` 失败 | 本轮结算为失败，柔和下行乐句。 |
| `manual_recall` 召回 | 主动召回生效，收束气流。 |
| `ui_confirm` 确认 | 开始、暂停、继续、下一关或重试等操作生效，轻点击声。 |
