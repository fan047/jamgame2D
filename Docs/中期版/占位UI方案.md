# 中期版占位 UI

历史记录。2026-11-08 起，UI 由团队自行设计实现，当前方向与接入约定以[首版正式 UI 方案](UI设计方案.md)为准；本文件保留当时的占位安排。

沿用现有游玩流程，把开始页、局内 HUD、暂停、结算和配置错误统一成一套矿洞风格的占位界面。先在工程里验证，随下一个中期 Windows 包一起发。正式 UI 的流程和素材继续等美术方向稿。

## 界面内容

| 界面 | 占位方案 |
|---|---|
| 开始页 | 复用矿洞背景和现有 Logo，显示「水晶矿洞」、主按钮「开始游戏」和一行操作提示。 |
| 局内 HUD | 顶部显示关卡、每轮球数、轮次和待确认奖励，右上放「暂停」，底部居中放「召回」。召回不可用时置灰。只有策划测试显示在场球、待发球、补行进度、运行状态和配置版本。 |
| 暂停 | 用半透明遮罩保留棋盘上下文。「继续游戏」为主按钮，配置重载为次按钮。正式模式显示「重载并重开」，策划测试显示「重载当前关」。两种模式均从暂停菜单进入配置重载。 |
| 结算 | 共用一个面板。本关通关展示已获奖励、下一关球数和「进入下一关」。失败显示原因和「重试本关」。全程通关以「重新开始全程」收尾。策划测试沿用「重测本关」和「返回选关」。 |
| 配置错误 | 复用结算面板骨架，展示现有中文错误说明，主按钮为「重新读取配置」。 |

## 实现约定

- 复用 `SampleScene` 的 World Space uGUI Canvas、中文 TMP 和现有视图组件。使用深蓝面板、金色主按钮、蓝灰次按钮和白色文字，参考旧样例的主次层级。面板与按钮使用 Unity 基础控件，方便正式素材替换。[旧占位样例](../成长版/UI样例/UI占位样例.png)
- HUD 锚定在发射金环上方，底部按钮放在棋盘下方。暂停和结算居中遮罩，收起局内控件。装饰和普通文字关闭射线检测，弹层拦住底层点击，按钮沿用现有命令和输入门禁。
- 策划选关面板沿用现有布局。策划暂停面板用纵向按钮组，后续音效功能交付时在此加入「重载音效」，与会重开当前关的配置重载分列。
- 把占位范围和验收要求并入现有中期版文档。每项独立改动自测通过后单独提交一次 Git。

## 验收

- 在 Unity PlayMode 验证开始、发射、召回、暂停恢复、失败重试、普通关通关、全程通关和配置错误恢复。更新已有 HUD 断言，分别检查正式游玩与策划测试的信息层级。
- 在 **540×960、1280×720** 及运行中缩放窗口时检查文字、按钮、棋盘和发射区，覆盖长配置版本与错误信息。确认按钮点击不穿透发球，失焦后恢复仍需显式点击「继续游戏」。
- 随下一个中期 Windows 包复测实际窗口，并在团队交接中标明占位 UI 的交付状态。
