# 首版正式 UI 设计与接入方案

2026-11-08。UI 由团队自行设计、实现与维护，不再等待美术方向稿。本文件取代《占位UI方案》中的视觉安排；游戏流程、命令及输入规则继续沿用现有实现。

当前交付是可交接设计与 HTML 交互预览，尚未改动 Unity 运行界面。Locus 仍暂停，等待本轮完整方向评审。

## 已确认的方向

- 一次覆盖开始页、局内 HUD、暂停、结算和配置错误。策划界面共用控件样式，保留现有工具布局与入口。
- 保留现有页面流转、按钮功能和操作方式。
- 清晰文字、少量图标、轻量切角面板，与切面矿石和断续岩壁背景统一。
- 每轮球数是 HUD 的主要数字，关卡次之，轮次弱化；待确认奖励大于 0 时显示“下关 +N 球”，为 0 时隐藏。
- 开始页以“水晶矿洞”和“开始游戏”为主，Logo 缩为辅助徽章。

## 共用视觉规则

沿用现有 NotoSansCJKsc-Regular 中文字体与 TMP 字体资源，正文优先可读。仅球数、结算关键数字及标题增加字号，避免整段文字同时强调。

颜色职责：
- 深蓝 #151E31 为舞台底色，面板 #19263A，次按钮 #2C3C53。
- 象牙白 #F5F0D8 为主要文字与主按钮底色，主按钮文字使用深蓝。
- 次要文字 #A5B0C2；橙金 #E1A24B 集中用于加球奖励，不作为所有按钮的默认色。
- 目标青绿保留给棋盘目标，UI 不增加持续发光边框。

控件采用平整底色和少量切角。以 540×960 作为设计量尺，按钮切角约 6px、面板约 12px；形状轮廓与矿石呼应，文字使用正常清晰字体。主操作最亮，次操作灰蓝，辅助说明降低对比。悬停略提亮、按下轻缩放、禁用灰化，沿用现有短按钮反馈与弹层淡入，不叠加持续装饰动效。

## 各页面安排

### 开始页

顶部与棋盘不显示局内危险线、发射点或 HUD。中央纵向排列小徽章、中文标题、开始按钮和简短操作提示。标题约 42px，开始按钮约 224×56px，提示 14px。删除“成长版试玩”等阶段性占位文案。

“开始游戏”继续发送现有 Start 命令，开始点击不能被当作发球。首版保留现有标题文字；Logo 可使用已有资源，之后按素材重设计方案替换，UI 布局不依赖大幅 Logo。

### 局内 HUD

位于发射区域上方，左右边距约 40px：
- 左侧关卡“03 / 09”，下方小字“第 4 轮”。
- 中间“每轮球数”标签与独立大数字“12 球”；这是本轮发球总量，不随单颗球发射而递减。
- 右侧 48px 以上的暂停按钮，使用简单双竖线图标并提供中文语义。
- 下方独立奖励条“下关 +3 球”，仅有待确认奖励时出现。奖励数字变化只动画该字段，关卡和球数不跟随缩放。

底部居中放约 168×48px 的“召回”，位于实际棋盘下方，并标注空格快捷键。仅 Volley 时可用，其他状态置灰，不隐藏导致布局跳动。按下生效时沿用现有召回反馈，避免叠播按钮确认音。

正式模式不显示在场球、待发球、补行、状态和配置版本；策划模式单独显示诊断文字，允许换行，不能挤占发射点或扩大整个 HUD 的字号。配置重载继续只从暂停菜单进入。

### 暂停

半透明全舞台遮罩保留棋盘上下文并拦截底层点击，收起局内可操作控件。面板约 408px 宽，中心对齐，文字左右留白约 32px。

“已暂停”为标题，“继续游戏”为象牙白主按钮。“重载并重开”为次按钮，其下说明“重载配置将从第 1 关重新开始”。

策划模式对应“重载当前关”，保留“重载音效”独立次按钮，音效版本和错误说明放在按钮组下方，不与会重开关卡的配置重载混合。

失焦暂停后仍需显式继续，不因恢复窗口焦点自动开局。

### 结算

普通通关、失败和全程通关复用同一面板骨架，各自只显示有用信息：
- 本关通关：标题“本关通关”，橙金显示已获得的本关奖励，独立显示下一关每轮球数；“进入下一关”为主按钮，“重新开始全程”为次按钮。
- 失败：标题“挑战失败”，显示现有原因；“重试本关”为主按钮，“重新开始全程”为次按钮。
- 全程通关：标题“全程通关”，显示实际已完成关数；“重新开始全程”为主按钮。
- 策划结果保留“测试通关／测试失败”、入关球数及“不推进正式流程”的说明，主按钮“重测本关”，次按钮“返回选关”。

不改变奖励在下一关生效、失败重试使用入关球数、目标击碎后等待本轮结算等业务规则。

### 配置错误

复用结算骨架，标题“配置错误”，中文原因沿用现有 ChineseText.Error。唯一主操作“重新读取配置”。错误信息自然换行，超长时在面板正文内滚动，按钮保持可见，不靠持续缩小字号容纳全文。

音效重载错误沿用当前不中断游戏、保留上一版声音的流程，复用本套文字和通知样式，不新增阻断弹窗。

## 结构与实现

继续使用 SampleScene 的 World Space uGUI Canvas、EventSystem 与现有 View，不更换 UI 框架，不整体销毁重建界面。设计量尺不等于 Unity 中直接写死屏幕坐标。

- 共用一份 UI 样式配置管理颜色、字号、间距和切角参数。使用简单 uGUI 自定义 Graphic 或可复用切角 Sprite 表现控件，按钮仍使用现有 UnityEngine.UI.Button 与 TMP。
- 在现有父对象内用锚点及布局容器调整，维持竖版舞台整体适配。横屏两侧保留环境留边，不把 HUD 拉到窗口最外侧。窗口缩放后，发射区、按钮和棋盘均在舞台安全范围内。
- HudView 拆成独立的关卡、球数、轮次、奖励与策划诊断引用。继续响应 flow.Changed，不增加每帧读取业务状态。
- ResultView 移除 Refresh 中覆盖颜色和文本区域尺寸的写死样式；显示逻辑只决定内容、显隐和主次按钮身份。PauseView 使用明确的引用，避免样式修改受 Help 名称查找限制。
- PlannerTestView 的运行时生成控件使用同一套样式；保留选关、球数和测试工具布局与功能。
- 正文及装饰关闭 Raycast Target；按钮与遮罩负责命中。保留现有 UI 发球拦截、开始与恢复帧输入门禁以及命令队列。
- 复用既有 PanelTransition 和 ButtonPressMotion；奖励弹动改为只针对奖励值。暂停期间弹层使用现有不受 timeScale 影响的时间。

接口变更限定在视图组件与共享视觉配置；现有 FlowCommand、关卡 JSON、音效 JSON 和物理规则无需改格式。层级或字段迁移时同步更新场景引用与已有 UI 断言。

## 预览与验收

[打开交互预览](UI设计预览/index.html)。它是独立 HTML 设计演示，不加载真实关卡、不调用 Unity、不改 JSON，页面数值和方块排布只用于表现信息层级。预览中切换界面、模式、奖励、召回状态和长错误可以查看设计分支。策划“返回选关”只标示现有入口，不在这里重做选关工具。

背景由已完成岩壁视觉稿用内置 image_gen 清理出无 UI、无方块的参考图，保存在预览目录；Logo 使用旧修整前备份，仅用于演示小徽章比例。二者不是本轮交付的正式运行资产。生成操作仅移除中央玩法元素，保留周边岩群与配色。

本次静态自测：检查 HTML 脚本语法、本地图片与字体引用、页面与操作分支、540×960 设计布局尺寸；结果见同目录自检记录。内置浏览器拒绝本地 file 地址，未尝试绕过；浏览器实际渲染与交互尚未实测。Unity 运行界面仍待接入，不将预览检查作为 PlayMode 或实际窗口验收。

实现后必须验证：
- 开始、发射、召回与置灰、暂停／显式恢复、配置重载、普通通关、失败重试、全程通关和配置错误恢复。
- 正式／策划信息分层，奖励为 0 与非 0、连续加球、下一关球数、重载音效及坏音效配置提示。
- 540×960、1280×720、运行中缩放窗口；长配置版本、长中文错误滚动、按钮无遮挡、发射区与棋盘安全间距。
- UI 点击不穿透发球；暂停时底层不可操作；失焦后恢复仍需点击继续；奖励只缩放对应数字。
- 更新已有 MidStageUiTests 等断言检查真实可见字段，保留现有输入与配置回归。完成 Unity PlayMode 后在实际 Windows 包复核。
- 每项独立改动自测通过后单独 Git 提交，记录实际结果和截图。沿用构建编号递增，不覆盖 Builds/17；保留无关未提交文件和旧修整成果。
