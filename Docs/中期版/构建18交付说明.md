## 本版 UI 变更

- 共用样式 `MineUIStyle`：深蓝 `#151E31` 舞台、面板 `#19263A`、次按钮 `#2C3C53`、象牙白 `#F5F0D8`、次要文字 `#A5B0C2`、奖励橙金 `#E1A24B`。设计 540×960 量尺按 `940/540` 换算到现有世界空间舞台，不写死屏幕坐标。
- `CutCornerImage`：轻切角 uGUI 图形（按钮 6、面板 12 设计像素）。仍使用 Unity `Button`、`Image` 与 TMP，未更换 UI 框架；既有 `PanelTransition`、`ButtonPressMotion` 继续复用。
- 开始页：小 Logo 徽章 + “水晶矿洞”标题 + 象牙白“开始游戏”主按钮 + 两行操作提示；删除“成长版试玩”；开始页隐藏发射点与危险线，进入局内后恢复。
- 局内 HUD：左侧“关卡 01 / 09”“第 N 轮”，中间主数字“12 球”（本轮总量，不随单球发射递减），右上暂停按钮（双竖线图标 + “暂停”中文语义）。奖励待确认大于 0 时显示独立“下关 +N 球”条，为 0 时隐藏；弹动只作用于奖励数字。
- 召回固定在棋盘下方居中并保留“空格召回”提示，仅 Volley 可用，其他状态置灰不隐藏。
- 暂停：全舞台遮罩拦住底层，居中 408 宽切角面板，“已暂停 / 继续游戏（象牙白主按钮）/ 重载并重开（次按钮）/ 重载说明”。策划模式增加“重载当前关”“重载音效”与音效版本、错误说明。
- 结算：普通通关、失败、全程通关复用同一面板骨架与固定操作位，只显示有用信息；本关奖励橙金单列、下一关每轮球数独立显示；全程通关显示“N / N”与“已完成全部关卡”，仅保留“重新开始全程”主按钮。
- 配置错误：标题“配置错误”，中文原因在正文滚动区换行，主按钮“重新读取配置”固定在滚动区外始终可见。
- 策划运行中控件改为共享样式；选关工具布局与入口不变，仅将“返回选关”快捷入口移到棋盘下方，避免遮住新的球数 HUD。

`ResultView.Refresh` 已移除反复覆盖颜色与文本区域尺寸的硬编码；`HudView` 拆出关卡、球数、轮次、奖励与诊断独立引用；`PauseView` 改用显式引用，不再依赖 `Help` 名称查找。正文与装饰关闭 Raycast Target，遮罩承担命中。

## 已知限制

- 运行素材仍是团队既有 19 张 PNG；本构建只做 UI 接入。方块与 256 方形裂痕在横竖形上的非等比运行缩放问题仍记录为后续项。
- `警告 486` 与构建 17 同源（既有 `FindFirstObjectByType`／`FindObjectsSortMode` 过时 API 提示等），本构建未清理。
- 长错误正文在面板内滚动，需鼠标滚轮或拖动；当前没有单独的滚动条控制器。
- 实际窗口复测使用临时配置副本，未改动仓库 `Config/`。
- 参考图与 HTML 预览里的演示数字、方块排布没有写入任何正式配置。
