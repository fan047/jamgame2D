# 水晶矿洞 · 中期版产品与内容

> 历史基线。当前玩法、关卡与视觉约定见[最终版产品与玩法](../最终版/产品与玩法.md)。

本文件是中期版的产品基线。后续玩法、策划工具和内容制作以本目录为准。当前可发给策划的包仍为构建 11。工程源码已有首批音效。正式九关、两张新背景和策划音效调节进入中期版交付范围。

## 玩法与成长

- 正式流程从第 1 关依次打到第 9 关。有效瞄准后左键发射一轮，空格或按钮主动召回。当前轮的球全部回收且没有待发球后统一结算。
- 每关恰有一个目标块，位于最后一条补行。目标块被击碎后等本轮结算再过关。目标未碎时，棋盘上移一格，下一条补行从底部进入。任一块顶端推进到危险线即失败。普通关通关后由玩家进入下一关，第 9 关通关显示全程完成。
- 每关每轮的球数在入关时确定，等于全局基础球数加已通关关卡实际取得的奖励。本关击碎的奖励先暂存，通关确认后从下一关起生效，换背景组也继续累计。失败重试保留入关球数并丢弃本次暂存奖励。重新开始全程清空成长并回第 1 关。
- 非最终关可有多个奖励块，每块可设合法的正整数奖励。`+3`、`+5`、`+8`、`+10` 是快捷值。目标块和奖励块互斥，最终关的布局使用普通块和目标块。累计入关球数须在正 Int32 范围内。
- 初始棋盘为 8×8，支持 `1×1`、`2×1` 和 `1×2`。补行为一格高，支持单格和横块。竖块从锚点向上占两行。血量降至初始血量的 2/3 和 1/3 时分别显示轻裂痕和重裂痕。受击闪白与缩放只作用于图形。
- Esc 或按钮暂停，点击「继续游戏」恢复。切出窗口自动暂停，回到窗口的首次激活点击只激活窗口。有效发射要求新一次按下，UI 上的手势、留边点击和跨回合长按均被拦截。

## 九关内容与美术

| 关卡 | 内容与素材 |
|---|---|
| 1–3 | 以策划确认的前三关为起点，第三关难度以策划最终复测配置为准。沿用现有矿洞背景。 |
| 4–6 | 策划制作三关，使用第二张背景。 |
| 7–9 | 策划制作三关，使用第三张背景。第 9 关负责最终结算。 |

两张新背景延续水晶玻璃矿洞主题、竖版舞台和棋盘安全区，缺图时程序回退现有矿洞背景。方块先复用现有皮肤，有余量再补同风格变体。开始页、HUD、暂停和结果等现有中文界面支持试玩。正式 UI 的页面组合、流程、造型和拆图等美术方向稿确定后再定。爆炸球、穿透球和补行竖块留作后续讨论。

## 策划工作台

- 现有工作台支持新增、复制、删除、重排及改名，整关总览纵向展示初始棋盘和全部补行。可点击任意组编辑、跳到指定补行，用独占整行的数值表连续修改血量或批量调整当前组。全局球参数、校验、撤销与重做继续使用现有入口。
- 策划可直接测试任意关，入关球数可选基础球数、拿满前关奖励或手填。正式流程始终根据实际奖励计算。策划测试的「重载当前关」重新读取球参与关卡，按稳定 ID 重建本关，便于调布局和数值。
- 中期版新增「音效」页。8 条音效各自支持试听、音量、静音、换 WAV 和恢复默认。配置全关共用，换素材保留该条音量和静音，普通块与目标块共用碎裂配置。策划只需交付一份 `audio.json`。暂停菜单中的「重载音效」用于留在同一局比较两版声音。

## 占位界面

本轮按[占位 UI 方案](占位UI方案.md)统一开始、HUD、暂停、结算和配置错误：深蓝面板、金色主按钮、蓝灰次按钮。正式 HUD 只显示关卡、每轮球数、轮次与待确认奖励；诊断信息仅策划测试显示。配置重载统一从暂停菜单进入，召回居中且不可用时置灰；弹层遮罩拦截底层点击。正式 UI 仍待美术方向稿。具体工程与随包验证状态以团队交接为准。

## 中期版完成条件

策划确认正式九关配置和第三关难度，实玩验收两处分组换图、真实加球成长与第 9 关结算。配套 Windows 包和离线工作台可以测试任意关、调整音效及在当前局重载音效。正式 UI 方向稿另行确认，现有中文界面可用于这轮内容与音效验收。
