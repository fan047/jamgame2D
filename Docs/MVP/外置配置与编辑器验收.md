# 外置配置与离线策划编辑器：使用与验收

日期：2026-10-30。分支：`codex/holedown-mvp`。本文覆盖首次 MVP 交付之后的外置配置增量；原有玩法规则不变。

## 1. 给策划的最短流程

1. 解压最新 `Builds/HoledownMVP-Windows.zip`。
2. 运行解压目录内的 `HoledownMVP/HoledownMVP.exe`。
3. 用 Chrome 或 Edge 打开同目录 `PlannerEditor/index.html`。
4. 在编辑器同时导入游戏 `Config/settings.json` 与 `Config/level.json`。刚打开编辑器时显示内置示例，不会自动读取游戏文件。
5. 调整参数或摆块，修改配置版本，校验通过后分别下载两份 JSON。
6. 用下载文件替换游戏 `Config` 内同名文件，注意浏览器可能添加 `(1)` 后缀。下载本身不会写回游戏目录。
7. 点击游戏 **Reload + Restart**，丢弃当前局并读取新配置。检查 HUD 的 S（球参数）/ L（关卡）版本。

不需要 Unity、网络服务或浏览器本地文件写权限。编辑器只通过用户选取文件导入、浏览器下载导出，不上传数据、不模拟物理。详细玩法／字段／试玩清单见 [策划使用说明](策划使用说明.md)；运行目录内另附 `策划快速上手.txt`。

工程源码编辑器：`Tools/PlannerEditor/index.html`。已构建副本：`Builds/Windows/PlannerEditor/index.html`。请连同旁边的 JS/CSS 一起保留，不要只复制 HTML。

## 2. 配置读取和优先级

- Windows 默认读取 exe 同目录 `Config/settings.json`、`Config/level.json`，不依赖启动时的工作目录。
- 两份都不存在：使用内置 Inspector 默认数据，HUD 显示 `Built-in`。
- 只缺一份、JSON 损坏、字段缺失／拼错／类型错误或关卡非法：显示 `Config error`、记录原因并禁止发射；不悄悄混用默认值。
- 启动、Restart、Reload + Restart 都会重新加载。**文件在飞行中改变，不影响正在运行的快照**；重载会终止旧局，不是保留进度热改规则。
- 每次加载创建独立 GameSettings 与 BoardState，不修改 ScriptableObject 或 JSON，不把伤害与推进写回文件。
- Unity Editor 默认仍使用 Inspector 资产，避免根目录 JSON 意外覆盖现有工作流。程序可在 `GameFlowController.externalConfigDirectory` 明确指定外部目录进行复现；策划无需操作此项。
- 两份 JSON 都要求整数 `schemaVersion: 1`，以及 `version`（1–32 个英文字母、数字、点、下划线或连字符）。版本不要求相同，HUD 分别显示，便于定位两份文件。
- 球参数、格子、占格与目标规则沿用原设计；错误含字段路径及从 0 开始的数组下标。
- 编辑器校验完整配置后才允许导出；编辑中可以暂时没有目标。目标必须唯一并位于最后一条补行。覆盖、越界摆块会被阻止。

维护的默认 JSON 位于工程根目录 `Config/`。策划在独立包里调好的副本应交回程序，核对后同步到工程 `Config/`，自测后单独提交，不能只留在 Git 忽略的 Builds 中。
